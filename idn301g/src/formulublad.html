Formúlublað · Megindleg ferlagreining

Allar formúlur megindlegrar ferlagreiningar (F7, BPM kafli 7) á einni til tveimur A4-síðum, með táknaskýringum. Notaðu blaðið þegar þú æfir reiknidæmin og prentaðu það út fyrir upprifjun. Athugaðu: á alvöru lokaprófinu eru engin hjálpargögn leyfð (aðeins vasareiknir), svo lærðu formúlurnar utan að og æfðu þig án blaðsins. Til að prófa tölur skaltu nota reiknivélarnar.

Mælikvarðar ferla

Tími (CT, bið, vinnsla), kostnaður (á mál, nýting), gæði (villur, endursendingar, ánægja), sveigjanleiki. Togast á: „Devil's quadrangle“.

Flæðisgreining metur: hringrásartíma (CT), kostnað á hvert mál (token = instance) og villuhlutfall.

$\sum p_i = 1$. Endursending í mesta lagi einu sinni: $T_1 + r\,T_2$. Hreiðraðar blokkir: innst fyrst. Heildar CT = blokkir lagðar saman.

Glæra 7: $CT = \frac{1}{1-0{,}2} + \max(1,3) + 3 + (0{,}6\cdot1+0{,}4\cdot2) = 8{,}65$ dagar.

Nýtni ferils og bundin leið

$$CTE = \frac{TCT}{CT}$$

$TCT$ = fræðilegur hringrásartími (bara vinnslutímar, sömu blokkareglur). $CT$ = með bið. Bið = $CT - TCT$.

CPM: $EF = ES + T$, $ES$ = mesta $EF$ forvera; $LS = LF - T$, $LF$ = minnsta $LS$ eftirfara. Slaki $= LS - ES$; bundin leið hefur slaka 0 og lengd hennar = CT.

Lögmál Little

$$WIP = \lambda \cdot CT \qquad CT = \frac{WIP}{\lambda} \qquad \lambda = \frac{WIP}{CT}$$

Gildir bara í stöðugu ferli. Sama tímaeining í $\lambda$ og $CT$. Í biðraðakerfi: $L = \lambda W$, $L_q = \lambda W_q$.

Framleiðslugeta, nýting, flöskuháls

$$\mu_p = \frac{uc}{ul} \qquad \rho_p = \frac{\lambda}{\mu_p}$$

$ul$ = vinnutími hóps á mál (blokkareglur, AND = summa, bara aðgerðir hópsins). $uc$ = vinnustundir hóps á tímabili, t.d. $8\text{ klst}\times$ fjöldi á dag.

Framleiðslugeta ferlis = $\min$ yfir hópa (flöskuhálsinn). Stöðugt ef $\rho_p \lt 1$.

M/M/1

$$\rho = \frac{\lambda}{\mu},\quad L_q = \frac{\rho^2}{1-\rho},\quad W_q = \frac{L_q}{\lambda},\quad W = W_q + \frac1\mu,\quad L = \lambda W$$

Jafngilt: $W_q = \dfrac{\lambda}{\mu(\mu-\lambda)}$, $L = \dfrac{\rho}{1-\rho}$, $W = \dfrac{1}{\mu-\lambda}$. Skilyrði $\rho \lt 1$.

Nauðsynlegt $\mu$ fyrir markmið $W_q$: $\mu = \dfrac{\lambda + \sqrt{\lambda^2 + 4\lambda/W_q}}{2}$.

M/M/c (formúla 7.13, Erlang C)

$$\rho = \frac{\lambda}{c\mu},\qquad L_q = \frac{(\lambda/\mu)^c\,\rho}{c!\,(1-\rho)^2\left(\dfrac{(\lambda/\mu)^c}{c!(1-\rho)} + \displaystyle\sum_{n=0}^{c-1}\frac{(\lambda/\mu)^n}{n!}\right)}$$

Síðan eins og M/M/1: $W_q = L_q/\lambda$, $W = W_q + 1/\mu$, $L = \lambda W$. Líkur á bið $P_w = \dfrac{(\lambda/\mu)^c/(c!(1-\rho))}{\text{svigi}}$, $L_q = P_w\dfrac{\rho}{1-\rho}$. Stöðugt ef $c \gt \lambda/\mu$.

Röð: (1) $\lambda/\mu$, $\rho$; (2) summa; (3) brot; (4) $L_q$; (5) $W_q$, $W$. Ein sameiginleg röð gefur styttri bið en $c$ sérraðir.

Hermun

Inntak: BPMN-líkan, komutaktur og dreifing, dreifing vinnslutíma, líkur á XOR-greinum, auðlindahópar (fjöldi, tímakaup, vinnutími). Úttak: dreifing CT, bið, nýting, kostnaður (t.d. BIMP). Gildrur: slembni, gæði gagna, 100 % afköst.

Takmarkanir flæðisgreiningar: meðaltöl, engin bið vegna auðlinda, krefst blokkaskipts líkans.
