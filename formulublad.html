Formúlublað

Allar formúlur úr hönnunarhlutanum á einum stað. Hentar til að fara yfir rétt fyrir prófið. Prentaðu blaðið (tvídálka á A4) ef prófið leyfir hjálpargögn, en athugaðu fyrst hvað kennarinn heimilar.

Nemar

Næmni: $S = \dfrac{\Delta y}{\Delta x}$. Línulegur nemi:

$$y = y_{min} + \frac{y_{max}-y_{min}}{x_{max}-x_{min}}(x - x_{min})$$

4-20 mA: $x_{min}$ gefur 4 mA. Frávik frá línuleika: % af mælisviði.

Fyrstu gerðar: $y(t) = \Delta x\,(1 - e^{-t/\tau})$. 63,2 % við $\tau$, 98,2 % við $4\tau$.

Álagsnemi: $\Delta R = R\,G\,\varepsilon$. Kóðaskífa: upplausn $\dfrac{2\pi r}{N}$.

Stillivíðnám með álagi: $e = V_s\dfrac{R_P}{R_L}(x^2 - x^3)$.

Jafnstraumshreyfill

$$v_a = L\frac{di}{dt} + R\,i + K_f\omega,\qquad \tau = K_\tau i,\qquad I\dot\omega + c\,\omega = \tau$$

$\tau_s = \dfrac{K_\tau}{R}v_a$,   $\omega_0 = \dfrac{v_a}{K_f}$,   $\tau = \tau_s\Bigl(1-\dfrac{\omega}{\omega_0}\Bigr)$

$P_{max} = \dfrac{\tau_s\omega_0}{4}$ við $\omega_0/2$.   $\tau_e = \dfrac{L}{R}$.

$L = 0$: $G_P = \dfrac{K_\tau/R}{Is + c + K_\tau K_f/R}$.

Gír: $I_{eff} = I_1 + I_2/N^2$. Lyfta: $\tau = \tau_n + m g r$ (+ $m a r$).

V/1000 RPM í V·s/rad: deila með 104,72.

Lykkjan og stöðugleiki

$$G_K = G_CG_PG_S,\qquad G_T = \frac{G_CG_P}{1+G_K}$$

$\omega_c$: $|G_K| = 1$.   $\omega_\pi$: $\angle G_K = -180^\circ$.

$\varphi_m = 180^\circ + \angle G_K(j\omega_c)$,   $A_m = \dfrac{1}{|G_K(j\omega_\pi)|}$.

Óstöðugt ef $|G_K(j\omega_\pi)| \ge 1$. Heppilegt: $\varphi_m$ 30°-60°, $A_m$ 2-5.

Rístími $t_r \approx 1{,}4/\omega_c$. Seinkun $e^{-Ls}$: mögnun 1, fasi $-\omega L$; $L_{max} = \varphi_m/\omega_c$.

$\mathrm{dB} = 20\log_{10}|G|$; $3\ \mathrm{dB}\approx\sqrt2$, $6\ \mathrm{dB}\approx2$, $20\ \mathrm{dB}=10$.

Truflanir og næmni

Truflun $v$ fyrir framan ferlið: $G_{VY} = \dfrac{G_P}{1+G_K}$. Meta við tíðni truflunar: mögnun $|G_{VY}(j\omega)|$, margfalda með útslagi.

Næmni: $S^{G_T}_{G_P} = \dfrac{1}{1+G_K}$,   $S^{G_T}_{G_S} = \dfrac{-G_K}{1+G_K}\approx-1$.

Stýrimerki $U$: hátíðnihegðun $|G_C(j\omega)|$ ræður mestu.

P, PI, PD, PID

P: $G_C = K$.   PI: $K\dfrac{1+T_Is}{T_Is}$,   $\omega_I = 1/T_I$.   PD: $K(1+T_Ds)$, $\omega_D = 1/T_D$.

$$\text{PID: } G_C = K\,\frac{1+T_Is}{T_Is}\,\frac{1+T_Ds}{1+T_Fs},\qquad |G_C(j\infty)| = K\frac{T_D}{T_F}$$

PI eyðir skekkju en lækkar fasann. PD hækkar fasann en magnar hátíðni.

Hönnunaruppskriftir

PI: $K$ svo $\varphi_m = \varphi_{min}+0{,}06\pi$; $\omega_I = 0{,}2\omega_c$, $T_I = \dfrac{1}{0{,}2\omega_c}$.

PD: $0{,}8\omega_\pi < \omega_D < 1{,}5\omega_\pi$; skoðaðu $G_CG_P$; veldu $K$ fyrir viðunandi $\varphi_m$.

PID: $T_D$ eins og PD; $0{,}2T_D < T_F < 0{,}4T_D$; skoðaðu $\dfrac{1+T_Ds}{1+T_Fs}G_P$; síðan $T_I$ og $K$ eins og PI.

Hafðu stýringuna eins einfalda og hægt er.
