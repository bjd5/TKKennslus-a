Ákvarðanir: if og switch

Tengist: Miðannarpróf 1 og lokapróf: if/else, switch, rökvirkjar

Forritið þarf að velja: ef notandinn er 18+, ef spilið passar, ef talan er slétt. Hér lærir þú að bera saman, sameina skilyrði og láta forritið velja leið. Í lokin leysir þú FizzBuzz, klassíska forritunarþraut.

Í lok kaflans geturðu

  • skrifað skilyrði með == != < > && || !
  • notað if / else if / else, ?: og switch
  • forðast algengustu if-villurnar

1 Samanburður gefur true eða false

int x = 5;
System.out.println(x == 5);   // jafnt
System.out.println(x != 5);   // ekki jafnt
System.out.println(x > 3);
System.out.println(x <= 4);

false

false

Varúð: == ber saman, = setur gildi. Og texta berðu saman með s.equals("já"), aldrei ==.

3 if og else

int temp = 3;
if (temp > 20) {
    System.out.println("Heitt");
} else if (temp > 5) {
    System.out.println("Fínt");
} else {
    System.out.println("Kalt");
}
Kalt

Java prófar skilyrðin að ofan og niður og keyrir aðeins fyrstu greinina sem er sönn. else grípur allt hitt.

Hvenær? if eitt og sér: „gerðu þetta ef…“. if/else: tvær leiðir. else if-keðja: margar leiðir, t.d. einkunnir.

Tvær gildrur: (1) Engin ; á eftir if (…): if (x > 5); gerir ekkert og blokkin keyrir alltaf. (2) Notaðu alltaf { }; án þeirra tilheyrir aðeins ein lína if-inu.

4 Einfaldaðu if-setningar

Samanburður er sjálfur true/false, svo oft þarftu ekkert if:

Langt

boolean isAdult;
if (age >= 18) {
    isAdult = true;
} else {
    isAdult = false;
}

Stutt

boolean isAdult = age >= 18;

5 Stutta if-ið: ? :

skilyrði ? gildiEfSatt : gildiEfÓsatt velur annað af tveimur gildum.

int a = 4, b = 9;
int max = a > b ? a : b;
String type = max % 2 == 0 ? "slétt" : "odda";
System.out.println(max + " er " + type);
9 er odda

Hvenær? Þegar þú velur á milli tveggja gilda í einni línu. Fyrir meira en það, notaðu venjulegt if.

6 switch

Velur grein eftir nákvæmu gildi (int, char eða String).

String role = "admin";
switch (role) {
    case "admin":
        System.out.println("Allur aðgangur");
        break;
    case "user":
    case "guest":
        System.out.println("Takmarkaður");
        break;
    default:
        System.out.println("Óþekkt");
}
Allur aðgangur

Varúð: gleymdu ekki break. Án þess heldur keyrslan áfram niður í næstu case, sama hvert gildið er. Það er algeng prófspurning.

switch eða if? switch þegar þú berð eina breytu saman við föst gildi (dagar, valmynd). if þegar þú þarft <, > eða sameinuð skilyrði.

Verkefni: FizzBuzz

Lestu tölu. Ef hún deilist með 5 prentaðu Fizz, ef hún deilist með 3 prentaðu Buzz, ef hún deilist með báðum prentaðu FizzBuzz, annars töluna sjálfa.

Vísbending: „deilist með 5“ er n % 5 == 0. Hugsaðu um í hvaða röð þú prófar.

Scanner input = new Scanner(System.in);
int n = input.nextInt();
if (n % 5 == 0 && n % 3 == 0) {
    System.out.println("FizzBuzz");
} else if (n % 5 == 0) {
    System.out.println("Fizz");
} else if (n % 3 == 0) {
    System.out.println("Buzz");
} else {
    System.out.println(n);
}
FizzBuzz

Sértækasta tilvikið (bæði) verður að koma fyrst. Ef n % 5 == 0 væri prófað fyrst fengi 15 bara „Fizz“.

Kóðaverkstæði
