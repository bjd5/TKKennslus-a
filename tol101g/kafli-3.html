Rökgildi og skilyrði

Tengist: Miðannarpróf 1 og lokapróf: if/else, switch, rökvirkjar

Forrit þurfa að velja: ef reiturinn er stigi, farðu upp; ef spilið passar, leggðu það niður. Hér lærir þú rökgildi (boolean), samanburðar- og rökvirkja, if/else, switch og skilyrðisvirkjann ?:, og algengustu gildrurnar sem spurt er um á prófinu.

Rökgildi og samanburður

Tagið boolean hefur tvö gildi: true og false. Samanburðarvirkjar skila boolean:

VirkiMerkingDæmi (x = 5)
==jafnt ogx == 5 → true
!=ekki jafnt ogx != 5 → false
< <= > >=minna, minna eða jafnt, …x >= 5 → true

Þrjár gildrur: (1) = er gildisveiting, == samanburður. (2) Berðu ekki saman double með ==; notaðu Math.abs(a - b) < 1e-9. (3) Berðu ekki saman strengi með ==; notaðu s.equals(t) (kafli 4).

Rökvirkjar

VirkiHeitiSatt þegar
!aneitun (not)a er ósatt
a && bog (and)bæði eru sönn
a || beða (or)að minnsta kosti annað er satt
a ^ bannaðhvort-eða (xor)nákvæmlega annað er satt

Forgangur: ! sterkast, svo reiknivirkjar, svo samanburður (< >, svo == !=), svo && og síðast ||. Þess vegna er a || b && c það sama og a || (b && c). Notaðu sviga ef þú ert í vafa.

Skammhlaup (short-circuit): && metur hægri hliðina ekki ef vinstri er ósönn, og || ekki ef vinstri er sönn. Það er gagnlegt til að verjast villum: if (n != 0 && total / n > 10) deilir aldrei með núlli.

De Morgan: !(a && b) er !a || !b og !(a || b) er !a && !b. „Ekki á bilinu 1-6“ er !(roll >= 1 && roll <= 6) = roll < 1 || roll > 6, eins og í Snakes & Ladders.

Bil: stærðfræðin skrifar 1 ≤ x ≤ 6, en í Java verður það 1 <= x && x <= 6. 1 <= x <= 6 er þýðingarvilla (boolean <= int).

if, else og else if

if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';          // hingað kemst aðeins score sem er < 90
} else if (score >= 70) {
    grade = 'C';
} else {
    grade = 'F';
}

Í keðju af else if er aðeins fyrsta sanna greinin keyrð; hinar eru hunsaðar. Röðin skiptir því máli: ef score >= 70 væri prófað fyrst fengju allir yfir 70 C.

Án slaufusviga tilheyrir aðeins næsta setning if-inu, sama hvernig inndrátturinn lítur út:

int x = 3;
if (x > 5)
    System.out.println("stórt");
    System.out.println("búið");
búið

Og hangandi else (dangling else) tilheyrir alltaf næsta if-i á undan sem ekki á else:

int a = 1, b = 5;
if (a > 2)
    if (b > 2)
        System.out.println("X");
else                        // tilheyrir if (b > 2)!
    System.out.println("Y");
(ekkert prentast)

a > 2 er ósatt, og else-ið tilheyrir innra if-inu, svo ekkert er keyrt.

Semíkomma á röngum stað: if (x > 5); er if með tómri setningu. Blokkin á eftir keyrir alltaf. Notaðu alltaf slaufusviga og settu aldrei ; beint á eftir svigunum.

Fullunnið dæmi: sérhljóð eða samhljóð (vika 6)

char c = input.nextLine().charAt(0);
final String VOWELS = "AEIOUaeiou";
if (c < 'A' || (c > 'Z' && c < 'a') || c > 'z') {
    System.out.println("other");
} else if (VOWELS.indexOf(c) >= 0) {
    System.out.println("vowel");
} else {
    System.out.println("consonant");
}

Fyrsta skilyrðið grípur allt sem er ekki enskur bókstafur (char eru tölur, svo < og > virka á þá). Annað skilyrðið leitar að stafnum í strengnum af sérhljóðum.

Fullunnið dæmi: er punktur í rétthyrningi?

if (px >= Math.min(r1x, r2x) && px <= Math.max(r1x, r2x) &&
    py >= Math.min(r1y, r2y) && py <= Math.max(r1y, r2y)) {
    System.out.println("P is inside R");
} else {
    System.out.println("P is outside R");
}

Math.min og Math.max sjá um að hornin geti komið í hvaða röð sem er.

switch

switch velur grein eftir gildi á int, char, String eða enum (ekki double eða boolean):

switch (day) {
    case 1:
        System.out.println("mánudagur");
        break;
    case 6:
    case 7:                         // tvö gildi sameinuð
        System.out.println("helgi");
        break;
    default:
        System.out.println("virkur dagur");
}

Mikilvægt: án break heldur keyrslan áfram í næstu case-grein (fall-through), óháð gildi hennar, þar til break eða endir switch-ins kemur. default er keyrt ef engin case passar.

int n = 2;
switch (n) {
    case 1: System.out.print("a");
    case 2: System.out.print("b");
    case 3: System.out.print("c");
        break;
    case 4: System.out.print("d");
}
bc

Nýrri Java (14+) leyfir líka örvaform sem hefur ekkert fall-through: case 6, 7 -> System.out.println("helgi");

Skilyrðisvirkinn ?:

skilyrði ? gildiEfSatt : gildiEfÓsatt er segð (ekki setning) sem skilar öðru af tveimur gildum:

int max = (a > b) ? a : b;
System.out.println(n + (n == 1 ? " spil" : " spil á hendi"));
String parity = (n % 2 == 0) ? "slétt" : "odda";

Samantekt

  • == ber saman, = gefur gildi. Strengir með equals, double með skekkjumörkum.
  • ! → && → ||; skammhlaup ver gegn villum.
  • Í else-if-keðju keyrir aðeins fyrsta sanna greinin.
  • Án slaufusviga á bara næsta setning við if; else tilheyrir næsta if-i á undan.
  • switch án break fellur í gegn í næstu case.
  • a ? b : c er segð sem skilar b eða c.

Æfingar

Kóðadæmi („hvað prentar forritið?“) með nýjum tölum í hvert skipti og skilningsspurningar úr kaflanum. Náðu 5 réttum svörum til að ljúka skrefinu. Þú færð skýringu eftir hvert svar og mátt halda áfram eins lengi og þú vilt.

Kóðaverkstæði

Hér vinnur þú með kóðann sjálfan, eins og á prófinu: raðar línum í rétt forrit, fyllir í eyður, finnur villur og rekur breytur skref fyrir skref. Leystu öll verkefnin til að ljúka skrefinu.
