Minnisblað: Java á einu blaði

Á prófinu máttu hafa eitt A4-blað með eigin handskrifuðum glósum (báðar hliðar). Hér er allt sem flestir þurfa að fletta upp, í þéttu formi. Notaðu það sem fyrirmynd þegar þú skrifar þitt eigið blað: að skrifa það sjálf(ur) er líka góð upprifjun. Síðan prentast á tvær síður.

Klasar

class Card {
    private int number;  private static int count = 0;
    public Card(int number) { this.number = number; count++; }
    public Card() { this(0); }
    public int getNumber() { return number; }
    public void setNumber(int n) { if (n >= 0) number = n; }
    public String toString() { return "C" + number; }
}

Smiður: sama nafn, ekkert skilatag; sjálfgefinn aðeins ef enginn er skrifaður · this.x = x · static = eitt eintak, ekkert this · null → NullPointerException · new Card[7] = 7 null.
