Villur: try, catch og throw

Tengist: Lokapróf: try/catch/finally, throw, throws, pakkar og aðgangur

Notandinn slær inn „abc“ þegar þú biður um tölu, eða einhver reynir að taka spil af tómum bunka. Í stað þess að forritið hrynji grípurðu villuna og bregst við. Í lokin: pakkar, sem skipta stóru verkefni í möppur.

Í lok kaflans geturðu

  • gripið villu með try/catch og vitað hvað keyrir hvenær
  • kastað villu sjálf(ur) með throw og búið til þína eigin
  • vitað hvenær throws er skylda

1 try og catch

String[] inputs = {"12", "abc", "7"};
int sum = 0;
for (String s : inputs) {
    try {
        sum += Integer.parseInt(s);
        System.out.println("ok: " + s);
    } catch (NumberFormatException e) {
        System.out.println("ekki tala: " + s);
    }
}
System.out.println("summa " + sum);
ok: 12
ekki tala: abc
ok: 7
summa 19

Ef villa verður í try hættir Java strax í try (afgangurinn keyrir ekki, „ok: abc“ prentast aldrei) og hoppar í catch. Svo heldur forritið áfram á eftir.

Hvenær? Þegar eitthvað utan þíns valds getur farið úrskeiðis: inntak frá notanda, skrár, texti sem á að verða tala.

2 finally keyrir alltaf

static int divide(int a, int b) {
    try {
        System.out.print("a");
        int r = a / b;
        System.out.print("b");
        return r;
    } catch (ArithmeticException e) {
        System.out.print("c");
        return -1;
    } finally {
        System.out.print("d");
    }
}
// í main:
System.out.println(" " + divide(10, 2));
System.out.println(" " + divide(10, 0));
abd 5
acd -1

finally keyrir alltaf: hvort sem villa varð eða ekki, og jafnvel þó return sé í try eða catch. Svona spurning er algeng á prófinu: raktu hana skref fyrir skref.

3 Fleiri catch: sértækt fyrst

try {
    …
} catch (ArrayIndexOutOfBoundsException e) {   // sértækt
    …
} catch (RuntimeException e) {                 // almennara
    …
} catch (Exception e) {                        // allt
    …
}

Varúð: catch (Exception e) grípur allt. Ef hún kemur fyrst ná hinar aldrei neinu, og þá þýðist kóðinn ekki. Og aldrei tóma catch-blokk { }: þá týnast villurnar.

5 Kasta villu sjálf(ur): throw

static void setAge(int age) {
    if (age < 0) {
        throw new IllegalArgumentException("Aldur getur ekki verið " + age);
    }
    System.out.println("Aldur: " + age);
}
// í main:
setAge(20);
try {
    setAge(-3);
} catch (IllegalArgumentException e) {
    System.out.println(e.getMessage());
}
Aldur: 20
Aldur getur ekki verið -3

Hvenær? Þegar aðferðin fær ógilt gildi og getur ekki haldið áfram. IllegalArgumentException fyrir ógildar færibreytur; e.getMessage() sækir skilaboðin.

6 Þín eigin villa og throws

class EmptyPileException extends Exception {
    public EmptyPileException(String msg) { super(msg); }
}
class Pile {
    private int[] items = new int[10];
    private int top = -1;
    public void push(int x) { items[++top] = x; }
    public int pop() throws EmptyPileException {
        if (top == -1) {
            throw new EmptyPileException("Bunkinn er tómur");
        }
        return items[top--];
    }
}
// í main:
Pile p = new Pile();
p.push(5);
try {
    System.out.println(p.pop());
    System.out.println(p.pop());
} catch (EmptyPileException e) {
    System.out.println(e.getMessage());
}
5
Bunkinn er tómur
Ef villan erfir…Þá þarftu…Dæmi
Exceptionannað hvort að grípa hana eða skrifa throws í hausinnIOException, þín eigin extends Exception
RuntimeExceptionhvorugt (en mátt)NullPointerException, IllegalArgumentException, EmptyStackException í UNO

throw vs throws: throw new X(…) kastar (inni í aðferðinni). throws X varar við (í hausnum).
