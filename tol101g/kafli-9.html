Hlutir sem vinna saman og UML

Tengist: Miðannarpróf 2 og lokapróf: UML-klasarit og tilvísanir

Í alvöru forriti vinna margir klasar saman: UNO-leikur hefur bunka og leikmenn, leikmaður hefur spil á hendi. Hér lærir þú að tengja klasa saman, lesa og teikna það í UML (prófið!) og nokkur gagnleg verkfæri fyrir texta.

Í lok kaflans geturðu

  • látið klasa geyma aðra hluti, einn eða mörg
  • lesið UML-örvarnar og þýtt þær í Java
  • notað split og StringBuilder

1 „Hefur“: hlutur sem eigindi

Ef A hefur B, verður B eigindi í A. Eitt B: venjulegt eigindi. Mörg B: fylki og teljari.

class Card {
    private int number;
    private char color;
    public Card(int n, char c) { number = n; color = c; }
    public int getNumber() { return number; }
    public String toString() { return "" + color + number; }
}
class Hand {
    private Card[] cards = new Card[10];
    private int count = 0;
    public void add(Card c) {
        cards[count] = c;
        count++;
    }
    public int points() {
        int sum = 0;
        for (int i = 0; i < count; i++) {
            sum += cards[i].getNumber();
        }
        return sum;
    }
    public String toString() {
        String s = "";
        for (int i = 0; i < count; i++) s += cards[i] + " ";
        return s;
    }
}
// í main:
Hand h = new Hand();
h.add(new Card(7, 'R'));
h.add(new Card(2, 'G'));
System.out.println(h + "= " + h.points());
R7 G2 = 9

Mynstrið: fylki + count. Lykkjan fer aðeins upp í count, því hin hólfin eru null (þá kæmi NullPointerException).

2 Geyma vísun eða afrit?

Ef smiður geymir hlut sem hann fékk, deila báðir sama hlutnum. Breyting utan frá sést inni. Viltu að klasinn eigi sinn eigin hlut? Afritaðu.

this.center = p;                               // deilt: p.shift(…) færir líka rétthyrninginn
this.center = new Point(p.getX(), p.getY());   // afrit: rétthyrningurinn á sinn eigin punkt

Úr tímanum: Triangle í geometry-dæminu afritar punktana sem hann fær; „independent“-útgáfan geymir vísanirnar.

Tölurnar á línunum segja hve margir: 1, 0..1 (má vanta), * (hve margir sem er), 1..*. Einn → eigindi; margir → fylki.

4 Margir klasar í verkefni

  • Hver public klasi í sinni skrá: Card.java, Hand.java…
  • Allar skrárnar byrja á sama package unogame; og eru í möppunni unogame/.
  • Aðeins einn klasi hefur main.
  • Á prófinu (Inspera): allir klasarnir í sama glugga, og þá ekki public fyrir framan class.

5 Verkfæri: split, toCharArray, StringBuilder

String[] parts = "R7 G2  B9".split(" +");   // eitt eða fleiri bil
System.out.println(parts.length + " " + parts[2]);
char[] letters = "uno".toCharArray();
System.out.println(letters[0]);
StringBuilder sb = new StringBuilder();
for (int i = 1; i <= 3; i++) {
    sb.append(i).append(",");
}
sb.reverse();
System.out.println(sb.toString());

StringBuilder þegar þú byggir upp texta í lykkju (hann breytist á staðnum; venjulegur String býr til nýjan texta í hverri umferð).

6 Enn og aftur: equals, ekki ==

String a = "uno";
String b = "uno";
String c = new String("uno");
System.out.println(a == b);
System.out.println(a == c);
System.out.println(a.equals(c));
true
false
true

Þess vegna ruglar == fólk: stundum virkar það (sami fasti texti er geymdur einu sinni), stundum ekki (nýr texti). equals virkar alltaf.
