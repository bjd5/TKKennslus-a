Forrit og reiknirit

Tengist: Lokapróf: hugtök, uppbygging Java-forrits og villutegundir

Hvað er reiknirit, hvað er forrit og hvað gerist þegar Java-kóði verður að keyrslu? Hér lærir þú uppbyggingu Java-forrits, hvernig það prentar og les inn, og hvaða þrjár tegundir villna þú munt rekast á. Á prófinu er spurt um hugtökin og þú þarft að geta lesið og skrifað einföld forrit án hjálpar frá ritlinum.

Reiknirit og forrit

Í fyrsta tímanum bjugguð þið til ykkar eigin reglur fyrir myllu (tic-tac-toe) fyrir fleiri en tvo leikmenn. Leikreglur og forrit eiga margt sameiginlegt: þær þurfa nákvæm fyrirmæli og skýran orðaforða, greiningar eftir skilyrðum („ef reiturinn er tómur…“), endurtekningar („haldið áfram þar til einhver vinnur“), staðlaðar aðferðir fyrir atvik sem endurtaka sig og skipulega framsetningu á stöðu leiksins (borðið, hver á leik) sem breytist.

Reiknirit (algorithm): endanleg runa af ótvíræðum skrefum sem leysir verkefni. Það má skrifa á íslensku, sem flæðirit eða sem sauðakóða (pseudocode).

Forrit (program): reiknirit skrifað á forritunarmáli svo tölva geti framkvæmt það.

Reiknirit lýsir hvað á að gera í hvaða röð. Það hefur þrjár grunnstoðir sem öll forritunarmál bjóða upp á: runu (skref hvert á eftir öðru), val (if/else) og endurtekningu (lykkjur). Kaflar 3 og 5 fjalla um seinni tvær.

Frá kóða til keyrslu

Tölvan sjálf skilur aðeins vélarmál: runur af bitum sem örgjörvinn framkvæmir. Fólk skrifar á æðra forritunarmáli (high-level language) eins og Java, og forrit þýða það yfir á eitthvað sem vélin getur keyrt.

SkrefHvað geristSkrá
1. SkrifaÞú skrifar frumkóða (source code) í ritli eða IDE (NetBeans, IntelliJ, VS Code).HelloWorld.java
2. ÞýðaÞýðandinn (compiler) javac athugar málfræðina og þýðir kóðann í bætikóða (bytecode).HelloWorld.class
3. KeyraJava-sýndarvélin (JVM, Java Virtual Machine) les bætikóðann og keyrir hann á þessari tölvu.java HelloWorld

Af því að bætikóðinn er sá sami á öllum stýrikerfum getur sama .class-skráin keyrt á Windows, macOS og Linux: „write once, run anywhere“. Það eina sem þarf er JVM fyrir hvert kerfi. JDK (Java Development Kit) inniheldur þýðandann og tólin; JRE (Java Runtime Environment) er bara það sem þarf til að keyra.

Uppbygging Java-forrits

/**
 * Fyrsta forritið mitt.
 */
public class HelloWorld {                     // klasi: sama nafn og skráin HelloWorld.java
    public static void main(String[] args) {  // aðalaðferðin: keyrslan byrjar hér
        System.out.println("Hello World!");   // setning endar á semíkommu
    }
}
  • Klasi (class): allt í Java býr í klösum. Klasinn sem er public verður að heita það sama og skráin (HelloWorld → HelloWorld.java). Hástafir skipta máli.
  • Aðalaðferðin public static void main(String[] args) er staðurinn þar sem JVM byrjar keyrsluna. Forrit án hennar er ekki hægt að keyra beint.
  • Setningar (statements) enda á ;. Blokkir eru afmarkaðar með slaufusvigum { } sem verða að standast á.
  • Athugasemdir (comments) hunsar þýðandinn: // út línuna, /* yfir margar línur */ og /** Javadoc */ sem lýsir klösum og aðferðum.
  • Java gerir greinarmun á há- og lágstöfum (case sensitive): Main, main og MAIN eru þrjú ólík nöfn.

Á prófinu (Inspera): ekki skrifa public fyrir framan klasa sem þú skrifar sjálf(ur) í ritilinn (public-aðferðir og -breytur eru í lagi), og þú mátt setja marga klasa í sama glugga.

Úttak: print, println og lausnarstafir

System.out.println(x) prentar x og fer svo í nýja línu. System.out.print(x) prentar án þess að skipta um línu. System.out.println() án gildis prentar bara línuskil.

System.out.print("Halló ");
System.out.print("heimur");
System.out.println("!");
System.out.println("Næsta lína");
Halló heimur!
Næsta lína

Plúsinn + skeytir saman strengjum: "Svar: " + 42 verður "Svar: 42". Varastu röðina: Java reiknar frá vinstri, svo 1 + 2 + "x" er "3x" en "x" + 1 + 2 er "x12". Meira um það í kafla 2.

Inntak með Scanner

Til að lesa af lyklaborðinu notarðu klasann Scanner úr pakkanum java.util:

import java.util.Scanner;   // efst í skránni

public class PieceOfCake {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        final double CAKE_RADIUS = 10;        // fasti, cm
        final double CAKE_HEIGHT = 5;
        double cakeVolume = Math.PI * Math.pow(CAKE_RADIUS, 2) * CAKE_HEIGHT;

        System.out.print("Enter number of guests: ");
        int numberOfGuests = input.nextInt();             // les heiltölu
        double pieceVolume = cakeVolume / (numberOfGuests + 1);   // gestir + gestgjafi
        System.out.println("Serving size: " + pieceVolume + " cm^3/person");
    }
}
AðferðLes
nextInt()næstu heiltölu (int)
nextDouble()næstu kommutölu (double)
next()næsta orð (fram að bili)
nextLine()afganginn af línunni, með bilum
nextBoolean()true eða false

Gildra: nextInt() skilur línuskilin eftir. Ef nextLine() kemur strax á eftir fær hún tóman streng. Lausn: kallaðu einu sinni á input.nextLine() til að „gleypa“ línuskilin.

Á prófinu: ekki prenta „Enter value:“ ef verkefnið biður ekki um það. Prentaðu bara það sem beðið er um, svo sjálfvirki yfirferðarmaðurinn ruglist ekki.

Nöfn og venjur

Auðkenni (identifiers) eru nöfn á klösum, breytum og aðferðum. Þau mega innihalda bókstafi, tölustafi, _ og $, en mega ekki byrja á tölustaf og mega ekki vera frátekin orð (class, int, if, new …).

Þrjár tegundir villna

TegundHvenær uppgötvastDæmi
Þýðingarvilla (syntax / compile error)Þegar javac þýðir. Forritið keyrir ekki.Vantar ;, slaufusvig standast ekki á, óskilgreind breyta, rangt tag (int x = "hæ";)
Keyrsluvilla (runtime error)Á meðan forritið keyrir; það stöðvast með undantekningu.Deilt með 0 í heiltölum (ArithmeticException), vísir utan fylkis, notandi slær inn „abc“ í nextInt()

Rökvillur eru hættulegastar því ekkert kerfi bendir á þær. Þess vegna þarftu að prófa forritið með inntaki þar sem þú veist rétta svarið, og hugsa reikniritið í heild áður en þú byrjar að kóða.

Samantekt

  • Reiknirit = ótvíræð skref; forrit = reiknirit á forritunarmáli.
  • .java → javac → .class (bætikóði) → JVM keyrir.
  • Public klasi heitir það sama og skráin; keyrsla byrjar í main.
  • print skiptir ekki um línu, println gerir það; \n, \t, \", \\.
  • Scanner input = new Scanner(System.in); og nextInt, nextDouble, next, nextLine.
  • Þýðingarvilla, keyrsluvilla, rökvilla.

Æfingar

Kóðadæmi („hvað prentar forritið?“) með nýjum tölum í hvert skipti og skilningsspurningar úr kaflanum. Náðu 5 réttum svörum til að ljúka skrefinu. Þú færð skýringu eftir hvert svar og mátt halda áfram eins lengi og þú vilt.

Kóðaverkstæði

Hér vinnur þú með kóðann sjálfan, eins og á prófinu: raðar línum í rétt forrit, fyllir í eyður, finnur villur og rekur breytur skref fyrir skref. Leystu öll verkefnin til að ljúka skrefinu.
