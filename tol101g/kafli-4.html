Texti: String og char

Tengist: Miðannarpróf 1 og lokapróf: char-reikningur og String-aðferðir

Nöfn, orð, setningar og spil eins og „R7“: allt er texti. Hér lærir þú helstu aðgerðirnar á texta, hvaða aðferð á að nota hvenær, og hvernig stafir (char) virka.

Í lok kaflans geturðu

  • sótt stafi og búta úr texta
  • leitað í texta og borið saman texta rétt
  • reiknað með stöfum (t.d. breytt '7' í 7)

1 Stafirnir eru númeraðir frá 0

String s = "Halló Java";
//          0123456789
String s = "Halló Java";
System.out.println(s.length());
System.out.println(s.charAt(0));
System.out.println(s.charAt(s.length() - 1));
10
H
a

Varúð: síðasti stafurinn er í sæti length() - 1. s.charAt(s.length()) hrynur (StringIndexOutOfBoundsException).

2 Bútar: substring

String s = "Halló Java";
System.out.println(s.substring(6));     // frá 6 til enda
System.out.println(s.substring(0, 5));  // 0 til 4 (5 ekki með)
Java
Halló

Regla: substring(byrjun, endir) tekur ekki stafinn í endir með. Fjöldi stafa = endir − byrjun.

3 Leita: indexOf og contains

String s = "banana";
System.out.println(s.indexOf('n'));       // fyrsta n
System.out.println(s.lastIndexOf('n'));   // síðasta n
System.out.println(s.indexOf("x"));       // finnst ekki
System.out.println(s.contains("nan"));
System.out.println(s.startsWith("ba"));
2
4
-1
true
true

Hvenær? contains ef þú þarft bara já/nei. indexOf ef þú þarft staðsetninguna (−1 = finnst ekki).

4 Breyta texta (býr til nýjan)

String s = "  Uno Game  ";
s = s.trim();
System.out.println(s.toUpperCase());
System.out.println(s.toLowerCase());
System.out.println(s.replace("Game", "spil"));
System.out.println(s);
UNO GAME
uno game
Uno spil
Uno Game

Mikilvægt: textinn sjálfur breytist aldrei. Aðferðirnar skila nýjum texta. s.toUpperCase(); eitt og sér gerir ekkert; skrifaðu s = s.toUpperCase();

5 Bera saman texta

String a = "uno";
String b = "UNO";
System.out.println(a.equals(b));
System.out.println(a.equalsIgnoreCase(b));
System.out.println("apa".compareTo("api") < 0);
false
true
true

Regla sem gildir alltaf: texti með equals, aldrei ==. == spyr hvort þetta sé sami hluturinn í minninu, sem getur verið rangt þó stafirnir séu eins (t.d. texti sem er lesinn inn).

compareTo segir til um stafrófsröð: neikvætt = á undan, 0 = eins, jákvætt = á eftir.

6 Skipta texta upp: split

String hand = "R7,G2,B9";
String[] cards = hand.split(",");
System.out.println(cards.length);
System.out.println(cards[1]);
3
G2

Hvenær? Þegar inntak er gefið sem ein lína með skilum, t.d. kommum eða bilum (split(" ")).

7 Stafir eru tölur

Hver char er í raun tala (kóði): 'A' = 65, 'a' = 97, '0' = 48. Því má reikna með stöfum.

char c = 'a';
System.out.println(c + 1);            // tala!
System.out.println((char) (c + 1));   // stafur
System.out.println('7' - '0');        // stafurinn 7 → talan 7
System.out.println("" + 'a' + 'b');   // texti
System.out.println(Character.isDigit('7'));
System.out.println(Character.toUpperCase('q'));
98
b
7
ab
true
Q

Gildra: 'a' + 'b' er 195 (tvær tölur lagðar saman), ekki „ab“. Byrjaðu á "" til að fá texta.

8 Fara í gegnum alla stafi

Þetta mynstur kemur aftur og aftur (lykkjur koma í næsta kafla):

String s = "Java er gaman";
int count = 0;
for (int i = 0; i < s.length(); i++) {
    char c = s.charAt(i);
    if (c == 'a') {
        count++;
    }
}
System.out.println(count);
4

Prófaðu: þú færð netfang eins og "anna@hi.is". Prentaðu notandanafnið (á undan @) og lénið (á eftir @).

String email = "anna@hi.is";
int at = email.indexOf('@');
System.out.println(email.substring(0, at));
System.out.println(email.substring(at + 1));
anna
hi.is

Æfingar

Kóðadæmi („hvað prentar forritið?“) með nýjum tölum í hvert skipti og skilningsspurningar úr kaflanum. Náðu 5 réttum svörum til að ljúka skrefinu. Þú færð skýringu eftir hvert svar og mátt halda áfram eins lengi og þú vilt.

Kóðaverkstæði

Hér vinnur þú með kóðann sjálfan, eins og á prófinu: raðar línum í rétt forrit, fyllir í eyður, finnur villur og rekur breytur skref fyrir skref. Leystu öll verkefnin til að ljúka skrefinu.
