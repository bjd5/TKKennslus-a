Aftur á kortið

Fylki

Tengist: Miðannarpróf 1 og lokapróf: fylki, tilvísanir og tvívíð fylki

Fylki (arrays) geyma mörg gildi af sama tagi undir einu nafni: borðið í Snakes & Ladders, stöðu leikmannanna, spilin í stokknum. Hér lærir þú að búa til fylki og fara í gegnum þau, hvað tilvísun þýðir (mikilvægasta hugtakið fyrir seinni hluta námskeiðsins), að senda fylki í aðferðir og að vinna með tvívíð fylki.

Að búa til fylki

int[] square = new int[4];               // 4 hólf, öll 0
double[] prices = new double[n];         // stærðin má vera breyta
String[] months = {"Jan", "Feb", "Mar"}; // frumstillt með gildum (stærð 3)
char[] grades = new char[] {'A', 'B'};   // sama, lengra form
  • Hólfin eru númeruð frá 0 til length - 1. a.length er eigindi, ekki aðferð (engir svigar).
  • Stærðin er föst eftir að fylkið er búið til.
  • Nýtt fylki fær sjálfgefin gildi: 0 fyrir tölur, false fyrir boolean, '\u0000' fyrir char og null fyrir hluti (t.d. String).
  • Vísir utan bilsins kastar ArrayIndexOutOfBoundsException við keyrslu.

Villan í taskA (Arrays.java):

for (int i = 1; i <= months.length; i++) {
    System.out.println(months[i]);     // sleppir "Jan" og kastar villu í lokin
}

Rétt: for (int i = 0; i < months.length; i++). Mundu: < length, ekki <= length.

Að fara í gegnum fylki

Venjuleg for-lykkja

for (int i = 0; i < a.length; i++) {
    a[i] = i * 10;       // má skrifa í fylkið
}

for-each (endurbætt for)

for (int x : a) {        // „fyrir hvert x í a“
    System.out.println(x);
}

for-each er styttri þegar þú þarft bara að lesa gildin. Þú hefur ekki vísinn, og ef þú breytir x breytist bara afrit; fylkið sjálft er óbreytt. Notaðu venjulega for-lykkju til að skrifa í fylki eða þegar þú þarft vísinn.

Algeng reiknirit

Summa og meðaltal

int sum = 0;
for (int x : a) sum += x;
double avg = (double) sum / a.length;

Stærsta gildi og vísir þess

int maxIdx = 0;
for (int i = 1; i < a.length; i++) {
    if (a[i] > a[maxIdx]) maxIdx = i;
}

Línuleg leit

int found = -1;
for (int i = 0; i < a.length; i++) {
    if (a[i] == key) { found = i; break; }
}

Snúa við á staðnum

for (int i = 0; i < a.length / 2; i++) {
    int t = a[i];
    a[i] = a[a.length - 1 - i];
    a[a.length - 1 - i] = t;
}

Hliðra til vinstri

int first = a[0];
for (int i = 1; i < a.length; i++) {
    a[i - 1] = a[i];
}
a[a.length - 1] = first;

Stokka (shuffle)

for (int i = 0; i < a.length; i++) {
    int j = (int) (Math.random() * a.length);
    int t = a[i]; a[i] = a[j]; a[j] = t;
}

Fylki eru tilvísanir

Breyta af tagi int[] geymir ekki tölurnar sjálfar heldur tilvísun (reference): „heimilisfangið“ á fylkinu í minninu. Þetta er taskD í Arrays.java:

int a = 42;
int b = a;            // gildið er afritað
b = b * 2;
System.out.println("a: " + a);

int[] c = {42, 32, 12};
int[] d = c;          // tilvísunin er afrituð
d[0] = d[0] * 2;      // breytir sameiginlega fylkinu
System.out.println("c[0]: " + c[0]);
a: 42
c[0]: 84

Eftir d = c vísa c og d á sama fylkið. Það er aðeins eitt fylki í minninu.

Til að fá sjálfstætt afrit þarf að búa til nýtt fylki og afrita gildin:

int[] copy = new int[c.length];
for (int i = 0; i < c.length; i++) copy[i] = c[i];
// eða:
int[] copy2 = java.util.Arrays.copyOf(c, c.length);
int[] copy3 = c.clone();
System.arraycopy(c, 0, copy, 0, c.length);   // (frá, frá-vísir, til, til-vísir, fjöldi)

c == d spyr hvort tilvísanirnar séu eins (sama fylkið), ekki hvort innihaldið sé eins. Fyrir innihald: Arrays.equals(c, d).

Fylki í aðferðum

Tilvísunin er afrituð í færibreytuna (gildisfærsla á tilvísuninni). Aðferðin sér því sama fylkið og getur breytt innihaldi þess, en ef hún lætur færibreytuna vísa á nýtt fylki hefur það engin áhrif á þann sem kallaði:

static void doubleAll(int[] x) {
    for (int i = 0; i < x.length; i++) x[i] *= 2;
}
static void replace(int[] x) {
    x = new int[] {0, 0, 0};    // bara staðbundið
}

int[] a = {1, 2, 3};
doubleAll(a);
replace(a);
System.out.println(Arrays.toString(a));
[2, 4, 6]

Aðferð getur líka skilað fylki: public static int[] copy(int[] in) { … return out; }.

Klasinn java.util.Arrays

AðferðGerir
Arrays.toString(a)strengur eins og [2, 4, 6] (System.out.println(a) prentar bara tilvísun eins og [I@1b6d3586)
Arrays.sort(a)raðar fylkinu í vaxandi röð (breytir því)
Arrays.copyOf(a, n)nýtt fylki af lengd n með fyrstu gildunum
Arrays.equals(a, b)sama innihald?
Arrays.fill(a, v)setur v í öll hólf
Arrays.binarySearch(a, key)helmingunarleit í röðuðu fylki

Tvívíð fylki

Tvívítt fylki er fylki af fylkjum: m[r] er röð r (sjálf int[]) og m[r][c] er stak í röð r, dálki c.

int[][] m = new int[3][4];       // 3 raðir, 4 dálkar, allt 0
int[][] t = {{1, 2, 3},
             {4, 5, 6}};           // 2 raðir, 3 dálkar
t.length        // 2   (fjöldi raða)
t[0].length     // 3   (fjöldi dálka í röð 0)
t[1][2]         // 6

for (int r = 0; r < t.length; r++) {
    for (int c = 0; c < t[r].length; c++) {
        System.out.print(t[r][c] + " ");
    }
    System.out.println();
}

Ójöfn fylki (ragged arrays) hafa raðir af mismunandi lengd: int[][] tri = {{1}, {1, 1}, {1, 2, 1}};. Þess vegna er öruggast að nota t[r].length í innri lykkjunni.

Fullunnið dæmi: að bylta (transpose)

public static int[][] transpose(int[][] in) {
    int[][] out = new int[in[0].length][in.length];   // dálkar verða raðir
    for (int r = 0; r < in.length; r++) {
        for (int c = 0; c < in[r].length; c++) {
            out[c][r] = in[r][c];
        }
    }
    return out;
}

Fylki í Snakes & Ladders

final int SQUARES = 100;
int[] offset = new int[SQUARES + 1];   // reitir 0..100; 0 = byrjunarreitur
offset[16] = -10;                      // snákur frá 16 niður í 6
offset[1] = 37;                        // stigi frá 1 upp í 38
int[] square = new int[PLAYERS];       // reitur hvers leikmanns, allir byrja í 0
…
square[player] += roll;
square[player] += offset[square[player]];   // fylgja snáki eða stiga

Hér er hönnunin þess virði að taka eftir: borðið er líkan (offset), staða leiksins er annað fylki (square), og vísirinn í offset er gildið í square.

Samantekt

  • int[] a = new int[n]; gefur n núll; vísar 0 … a.length - 1.
  • for (int i = 0; i < a.length; i++) til að skrifa; for (int x : a) til að lesa.
  • b = a afritar tilvísunina; bæði nöfnin vísa á sama fylkið.
  • Aðferð getur breytt innihaldi fylkis sem hún fær, en ekki tilvísun þess sem kallaði.
  • Arrays.toString, sort, copyOf, equals.
  • m.length raðir, m[r].length dálkar; m[r][c].

Æfingar

Kóðadæmi („hvað prentar forritið?“) með nýjum tölum í hvert skipti og skilningsspurningar úr kaflanum. Náðu 5 réttum svörum til að ljúka skrefinu. Þú færð skýringu eftir hvert svar og mátt halda áfram eins lengi og þú vilt.

Kóðaverkstæði

Hér vinnur þú með kóðann sjálfan, eins og á prófinu: raðar línum í rétt forrit, fyllir í eyður, finnur villur og rekur breytur skref fyrir skref. Leystu öll verkefnin til að ljúka skrefinu.
