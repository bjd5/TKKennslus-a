Kafli 7: Fylki

Þessi kafli opnast þegar þú hefur náð kaflaprófinu í kafla 6 með einkunn 6 eða hærra.

Aftur á kortið

Kafli 7 af 12 · Vika 7 · Liang kaflar 7 og 8

Fylki

Tengist: Miðannarpróf 1 og lokapróf: fylki, tilvísanir og tvívíð fylki

Þegar þú þarft 12 mánuði, 4 leikmenn eða 101 reit á borði býrðu ekki til 101 breytu; þú býrð til eitt fylki. Hér lærir þú að búa til fylki, fara í gegnum þau, nota tilbúnu aðgerðirnar í Arrays og vinna með töflur (tvívíð fylki).

Í lok kaflans geturðu

  • búið til fylki og lesið og skrifað í það
  • fundið summu, stærsta gildi og leitað í fylki
  • skilið af hverju b = a afritar ekki fylki

1 Búa til fylki

int[] scores = new int[4];          // 4 hólf, öll 0
scores[0] = 10;
scores[3] = 7;
String[] months = {"Jan", "Feb", "Mar"};   // með gildum
System.out.println(scores.length);
System.out.println(months[1]);
System.out.println(Arrays.toString(scores));
4
Feb
[10, 0, 0, 7]

Tvær leiðir: new int[n] þegar þú veist stærðina en ekki gildin; {…} þegar þú veist gildin.

Varúð: hólfin eru 0 til length - 1. scores[4] hrynur (ArrayIndexOutOfBoundsException). Og length fyrir fylki er án sviga (ólíkt s.length() fyrir texta).

2 Fara í gegnum fylki

int[] a = {4, 8, 15, 16};
for (int i = 0; i < a.length; i++) {
    a[i] = a[i] * 2;              // skrifa: þarf i
}
for (int x : a) {                 // lesa: for-each
    System.out.print(x + " ");
}
8 16 30 32

Hvor? for (int x : a) þegar þú bara lest gildin. Venjuleg for þegar þú þarft að breyta fylkinu eða vita númer hólfsins.

3 Tilbúnar aðgerðir: Arrays

int[] a = {5, 2, 9, 1};
System.out.println(Arrays.toString(a));
Arrays.sort(a);
System.out.println(Arrays.toString(a));
int[] b = Arrays.copyOf(a, a.length);
System.out.println(Arrays.equals(a, b));
[5, 2, 9, 1]
[1, 2, 5, 9]
true
Ég vil…Nota
prenta fylkiArrays.toString(a) (ekki bara println(a), það gefur rugl eins og [I@1b6d)
raðaArrays.sort(a);
afritaArrays.copyOf(a, a.length)
bera saman innihaldArrays.equals(a, b)

Muna: import java.util.Arrays; efst.

4 Það sem þú gerir oftast við fylki

int[] a = {3, 9, 4, 9, 1};
int sum = 0;
for (int x : a) {
    sum += x;
}
int maxIdx = 0;
for (int i = 1; i < a.length; i++) {
    if (a[i] > a[maxIdx]) maxIdx = i;
}
int found = -1;
for (int i = 0; i < a.length; i++) {
    if (a[i] == 4) { found = i; break; }
}
System.out.println(sum + " " + (double) sum / a.length);
System.out.println(a[maxIdx] + " í hólfi " + maxIdx);
System.out.println("4 í hólfi " + found);
26 5.2
9 í hólfi 1
4 í hólfi 2

Mynstrin: summa (byrja í 0), stærsta (byrja í fyrsta stakinu, ekki 0), leit (byrja í −1 = „ekki fundið“, break þegar fundið).

5 Gildran: b = a afritar ekki

int x = 42;
int y = x;
y = 0;
System.out.println(x);        // tala: afritað

int[] c = {42, 32, 12};
int[] d = c;                  // SAMA fylkið!
d[0] = 0;
System.out.println(c[0]);
42
0

Fylkisbreyta geymir ekki tölurnar sjálfar heldur vísun á fylkið. d = c afritar vísunina, svo bæði nöfnin benda á sama fylkið. Þetta er dæmið úr tímanum (taskD) og kemur aftur í hlutum (kafli 8).

Viltu sjálfstætt afrit? int[] d = Arrays.copyOf(c, c.length);

Sama í aðferðum: ef aðferð fær fylki og breytir hólfi, sést breytingin úti í main.

6 Fylki í og úr aðferðum

static int sum(int[] a) {
    int s = 0;
    for (int x : a) s += x;
    return s;
}
static int[] reversed(int[] a) {
    int[] r = new int[a.length];
    for (int i = 0; i < a.length; i++) {
        r[i] = a[a.length - 1 - i];
    }
    return r;
}
// í main:
int[] a = {1, 2, 3};
System.out.println(sum(a));
System.out.println(Arrays.toString(reversed(a)));
6
[3, 2, 1]

7 Töflur: tvívíð fylki

int[][] grid = {
    {1, 2, 3},
    {4, 5, 6}
};
System.out.println(grid.length);       // raðir
System.out.println(grid[0].length);    // dálkar
System.out.println(grid[1][2]);        // röð 1, dálkur 2
for (int r = 0; r < grid.length; r++) {
    for (int c = 0; c < grid[r].length; c++) {
        System.out.print(grid[r][c] + " ");
    }
    System.out.println();
}
2
3
6
1 2 3
4 5 6

Hvenær? Leikjaborð, töflur, myndir. new int[raðir][dálkar]; fyrst röð, svo dálkur: grid[r][c].

8 Úr tímanum: borðið í Snakes & Ladders

final int SQUARES = 100;
int[] offset = new int[SQUARES + 1];   // reitir 0..100, allir 0
offset[16] = -10;                      // snákur: 16 → 6
offset[1] = 37;                        // stigi: 1 → 38
int[] square = new int[PLAYERS];       // hvar hver leikmaður er (allir í 0)

square[player] += roll;
square[player] += offset[square[player]];   // fylgja snáki/stiga

Tvö fylki: eitt lýsir borðinu, hitt stöðu leikmannanna. Gildið í öðru er notað sem hólfanúmer í hinu.

Prófaðu: teningi er kastað 60 sinnum. Teldu hve oft hver tala (1-6) kom upp og prentaðu niðurstöðuna. Vísbending: int[] count = new int[7]; og count[roll]++.

int[] count = new int[7];          // nota hólf 1-6
for (int i = 0; i < 60; i++) {
    int roll = (int) (Math.random() * 6) + 1;
    count[roll]++;
}
for (int f = 1; f <= 6; f++) {
    System.out.println(f + ": " + count[f]);
}

Æfingar

Kóðadæmi („hvað prentar forritið?“) með nýjum tölum í hvert skipti og skilningsspurningar úr kaflanum. Náðu 5 réttum svörum til að ljúka skrefinu. Þú færð skýringu eftir hvert svar og mátt halda áfram eins lengi og þú vilt.

Kóðaverkstæði

Hér vinnur þú með kóðann sjálfan, eins og á prófinu: raðar línum í rétt forrit, fyllir í eyður, finnur villur og rekur breytur skref fyrir skref. Leystu öll verkefnin til að ljúka skrefinu.
