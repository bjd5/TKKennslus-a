Lykkjur: endurtaka

Lykkjur endurtaka kóða: telja upp í 10, lesa tölur þar til notandinn hættir, fara í gegnum alla stafi texta. Hér lærir þú þrjár gerðir og hvenær hver á við, og bætir svo lánareikninn þannig að hann hafni rugli. Í lokin sérðu leikjalykkjuna úr Snakes & Ladders úr tímunum.

Í lok kaflans geturðu

  • valið á milli for, while og do-while
  • notað break og continue
  • rakið lykkju á blaði (algeng prófspurning)

1 for: þegar þú veist hve oft

for (int i = 1; i <= 5; i++) {
    System.out.print(i + " ");
}
System.out.println();
for (int i = 10; i > 0; i -= 3) {
    System.out.print(i + " ");
}
1 2 3 4 5
10 7 4 1

Hausinn hefur þrjá hluta: byrjun (int i = 1), halda áfram á meðan (i <= 5) og skref (i++).

Hvenær? Teljari, ákveðinn fjöldi skipta, fara í gegnum texta eða fylki: for (int i = 0; i < n; i++) fer n sinnum.

Varúð: < eða <=? Frá 0 með < n og frá 1 með <= n fara bæði n sinnum. Rangt val = einni umferð of mikið/lítið.

2 while: á meðan eitthvað er satt

Scanner input = new Scanner(System.in);
int sum = 0;
int n = input.nextInt();
while (n != 0) {          // 0 = hætta
    sum += n;
    n = input.nextInt();
}
System.out.println("Summa: " + sum);
Summa: 18

(Inntak: 5 3 10 0.)

Hvenær? Þegar þú veist ekki fyrirfram hve oft: lesa þar til notandinn slær inn 0, kasta teningi þar til einhver vinnur.

Varúð: eitthvað inni í lykkjunni verður að breyta skilyrðinu, annars er hún endalaus.

3 do-while: að minnsta kosti einu sinni

Scanner input = new Scanner(System.in);
int roll;
do {
    System.out.print("Kast (1-6)? ");
    roll = input.nextInt();
} while (roll < 1 || roll > 6);
System.out.println();
System.out.println("Þú kastaðir " + roll);
Kast (1-6)? Kast (1-6)? Kast (1-6)?
Þú kastaðir 4

(Inntak: 9 0 4.)

Hvenær? Að spyrja aftur og aftur þar til svarið er löglegt. Þetta er nákvæmlega lykkjan sem les kast í Snakes & Ladders.

Muna: semíkomma á eftir while (…); í do-while.

4 break og continue

for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) {
        continue;   // sleppa þessari umferð
    }
    if (i > 7) {
        break;      // hætta alveg
    }
    System.out.print(i + " ");
}
1 2 4 5 7

Hvenær? break: þú fannst það sem þú leitaðir að, eða leiknum er lokið. continue: sleppa ákveðnum tilvikum.

5 Lykkja inni í lykkju

for (int row = 1; row <= 3; row++) {
    for (int col = 1; col <= 4; col++) {
        System.out.print(row * col + "\t");
    }
    System.out.println();
}
1	2	3	4
2	4	6	8
3	6	9	12

Hvenær? Töflur, mynstur, tvívíð fylki. Innri lykkjan klárast alveg fyrir hverja umferð ytri lykkjunnar.

6 Rekja lykkju (prófið!)

Á prófinu er spurt „hvað prentar þetta?“. Gerðu töflu: einn dálk fyrir hverja breytu, eina línu fyrir hverja umferð.

int a = 1, b = 0;
while (a < 20) {
    b += a;
    a *= 3;
}
System.out.println(a + " " + b);

7 Mynstur sem þú notar aftur og aftur

Telja og leggja saman

int count = 0, sum = 0;
for (int i = 1; i <= 100; i++) {
    if (i % 7 == 0) {
        count++;
        sum += i;
    }
}

Tölustafir tölu

while (n > 0) {
    int digit = n % 10;  // síðasti
    // … nota digit
    n = n / 10;          // henda honum
}

Stærsta gildið

int max = input.nextInt();  // fyrsta
for (int i = 1; i < n; i++) {
    int x = input.nextInt();
    if (x > max) max = x;
}

Er talan frumtala?

boolean prime = n > 1;
for (int d = 2; d * d <= n; d++) {
    if (n % d == 0) {
        prime = false;
        break;
    }
}

Verkefni: lánareiknir 2.0

Bættu lánareikninn úr kafla 2: hann á að spyrja aftur ef upphæðin er ekki á bilinu 1.000.000-100.000.000, vextirnir ekki 0-30 eða árin ekki 1-40. Prentaðu svo greiðsluna, og að auki eftirstöðvar lánsins eftir hvert 5. ár.

Vísbending: do-while fyrir hvert inntak. Eftirstöðvar eftir p greiðslur: P · ((1+r)n − (1+r)p) / ((1+r)n − 1).

Scanner input = new Scanner(System.in);
int principal;
do {
    principal = input.nextInt();
} while (principal < 1_000_000 || principal > 100_000_000);
double annualRate;
do {
    annualRate = input.nextDouble();
} while (annualRate <= 0 || annualRate > 30);
int years;
do {
    years = input.nextInt();
} while (years < 1 || years > 40);

double r = annualRate / 100 / 12;
int n = years * 12;
double factor = Math.pow(1 + r, n);
System.out.printf("Greiðsla: %.0f kr%n", principal * r * factor / (factor - 1));
for (int year = 5; year <= years; year += 5) {
    double balance = principal * (factor - Math.pow(1 + r, year * 12)) / (factor - 1);
    System.out.printf("Eftir %d ár: %.0f kr%n", year, balance);
}
Greiðsla: 231545 kr
Eftir 5 ár: 27682182 kr
Eftir 10 ár: 24228992 kr
Eftir 15 ár: 19084271 kr
Eftir 20 ár: 11419430 kr
Eftir 25 ár: 0 kr

(Inntak: 500 30000000 -2 8 25: 500 og −2 er hafnað.) 1_000_000 er bara læsilegri leið að skrifa milljón.

8 Úr tímanum: leikjalykkjan

Svona byggir Snakes & Ladders á lykkjum: endalaus do-while(true) sem break stöðvar þegar einhver vinnur, og % PLAYERS til að fara hringinn á milli leikmanna.

do {
    roll = (int) (Math.random() * 6 + 1);
    if (square[player] + roll <= SQUARES) {          // ekki fara yfir 100
        square[player] += roll;
        square[player] += offset[square[player]];    // snákur eða stigi
    }
    if (square[player] == SQUARES) {
        break;                                       // einhver vann
    }
    if (roll != 6) {                                 // 6 = gera aftur
        player = (player + 1) % PLAYERS;
    }
} while (true);
