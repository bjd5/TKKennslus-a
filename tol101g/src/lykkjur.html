Lykkjur

Lykkjur endurtaka setningar: að kasta teningi þar til einhver vinnur, að fara í gegnum alla stafi strengs eða öll spil í stokki. Hér lærir þú while, do-while og for, break og continue, hreiðraðar lykkjur og hvernig þú rekur lykkju skref fyrir skref, sem er ein algengasta prófspurningin.

while-lykkjan

int i = 1;                 // 1. frumstilling
while (i <= 5) {           // 2. skilyrði, prófað FYRIR hverja umferð
    System.out.print(i + " ");
    i++;                   // 3. uppfærsla: annars endalaus lykkja
}
System.out.println("| i = " + i);
1 2 3 4 5 | i = 6

Skilyrðið er prófað áður en hver umferð byrjar. Ef það er ósatt í upphafi keyrir lykkjan aldrei. Eftir lykkjuna er skilyrðið ósatt (hér i = 6).

Lykkja með vaktgildi (sentinel)

int sum = 0;
int n = input.nextInt();
while (n != 0) {           // 0 merkir „búið“
    sum += n;
    n = input.nextInt();   // lesa næsta í lok umferðar
}
System.out.println("Summa: " + sum);

do-while-lykkjan

Í do-while er skilyrðið prófað eftir umferðina, svo lykkjan keyrir að minnsta kosti einu sinni. Hún hentar til að lesa inntak þar til það er löglegt, eins og í Snakes & Ladders:

int roll;
do {
    roll = input.nextInt();
} while (roll < 1 || roll > 6);   // endurtaka á meðan kastið er ólöglegt
                                    // takið eftir semíkommunni!

for-lykkjan

for safnar frumstillingu, skilyrði og uppfærslu í eina línu. Hún er eðlilegasti kosturinn þegar fjöldi umferða er þekktur:

for (int i = 0; i < 5; i++) {     // i = 0, 1, 2, 3, 4  (5 umferðir)
    System.out.print(i * i + " ");
}
// 0 1 4 9 16

Röðin í hverri umferð: skilyrði → líkami → uppfærsla → skilyrði → … Frumstillingin keyrir einu sinni í byrjun. Breyta sem er lýst í for-hausnum (int i) er aðeins til inni í lykkjunni; eftir hana er i óþekkt (þýðingarvilla).

HausGildi á iUmferðir
for (int i = 0; i < n; i++)0 … n−1n
for (int i = 1; i <= n; i++)1 … nn
for (int i = n; i > 0; i--)n … 1n
for (int i = 0; i < n; i += 2)0, 2, 4 … < n⌈n/2⌉
for (int i = 1; i < 100; i *= 2)1, 2, 4 … 647

Fjöldi umferða í for (int i = a; i < b; i++) er b − a; með <= er hann b − a + 1.

Klassískar villur: (1) Einum of mikið/lítið (off-by-one): <= í stað < eða öfugt, sérstaklega með length(). (2) for (…); með semíkommu: líkaminn verður tóm setning og blokkin á eftir keyrir einu sinni. (3) Endalaus lykkja: uppfærslan gleymist eða færir breytuna í ranga átt (i-- þegar i < n).

break og continue

  • break hættir í innstu lykkjunni (eða switch) strax.
  • continue sleppir afganginum af þessari umferð og fer í næstu (í for-lykkju er uppfærslan samt keyrð).
for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) continue;   // sleppa 3, 6, 9
    if (i > 7) break;           // hætta við 8
    System.out.print(i + " ");
}
1 2 4 5 7

Leikjalykkjan í Snakes & Ladders er do { … } while (true);: endalaus lykkja sem break rýfur þegar einhver nær reit 100.

Hreiðraðar lykkjur

Innri lykkjan keyrir allar sínar umferðir fyrir hverja umferð ytri lykkjunnar:

for (int row = 1; row <= 4; row++) {
    for (int col = 1; col <= row; col++) {
        System.out.print("*");
    }
    System.out.println();
}

**
***

Heildarfjöldi umferða innri lykkjunnar hér er 1 + 2 + 3 + 4 = 10. Ef innri lykkjan fer alltaf m sinnum og sú ytri n sinnum er fjöldinn n·m.

Algeng mynstur

Summa og fjöldi

int sum = 0, count = 0;
for (int i = 1; i <= n; i++) {
    if (i % 3 == 0) {
        sum += i;
        count++;
    }
}

Stærsta gildi

int max = input.nextInt();   // fyrsta gildið
for (int i = 1; i < n; i++) {
    int x = input.nextInt();
    if (x > max) max = x;
}

Tölustafir tölu

int digitSum = 0, rev = 0;
while (n > 0) {
    int d = n % 10;      // síðasti stafur
    digitSum += d;
    rev = rev * 10 + d;  // byggja öfuga tölu
    n /= 10;             // henda síðasta staf
}

Er n frumtala?

boolean prime = n > 1;
for (int d = 2; d * d <= n; d++) {
    if (n % d == 0) {
        prime = false;
        break;
    }
}

Að rekja lykkju

Á prófinu áttu að geta sagt nákvæmlega hvað lykkja prentar, án tölvu. Gerðu töflu með dálki fyrir hverja breytu og línu fyrir hverja umferð:

int a = 1, b = 0;
while (a < 20) {
    b += a;
    a *= 3;
}
System.out.println(a + " " + b);

Samantekt

  • while: 0 eða fleiri umferðir; do-while: 1 eða fleiri; for: þekktur fjöldi.
  • Röð í for: frumstilling (1×), svo skilyrði → líkami → uppfærsla.
  • i < n frá 0 gefur n umferðir; i <= n frá 1 líka.
  • break hættir í innstu lykkju; continue fer í næstu umferð.
  • Hreiðraðar: innri lykkjan klárast fyrir hverja ytri umferð.
  • Raktu með töflu: ein lína á umferð, einn dálkur á breytu.
