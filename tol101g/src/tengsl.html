Tengsl hluta og UML

Hlutir standa sjaldnast einir: leikmaður heldur á spilum, UNO-leikur hefur dráttarbunka og kastbunka, þríhyrningur hefur þrjá punkta. Hér lærir þú tengslategundirnar (samband, safntengsl, samsetning, háð), hvernig þær eru teiknaðar í UML-klasariti og þýddar í Java, söfn af hlutum í fylkjum, og meira um String-klasann (óbreytanleika, internering, split og StringBuilder).

UNO-spilið sem klasarit

Leikurinn býr til bunkana og leikmennina (samsetning). Leikmaður hefur spil á hendi sem koma úr dráttarbunkanum og fara í kastbunkann, svo þau lifa áfram þó þau fari af hendinni (safntengsl). Bæði DrawPile og DiscardPile eru StackOfCards (erfðir, kafli 10).

Tengsl í Java

Safntengsl: tilvísanir utan frá

public class Course {
    private String name;
    private Student[] students = new Student[100];
    private int count = 0;

    public void addStudent(Student s) {
        students[count++] = s;   // geymir tilvísunina
    }
    public int getNumberOfStudents() {
        return count;
    }
}

Samsetning: heildin býr til hlutana

public class Triangle {
    private Point[] corners = new Point[3];

    public Triangle(Point p, Point q, Point r) {
        corners[0] = new Point(p.getX(), p.getY());
        corners[1] = new Point(q.getX(), q.getY());
        corners[2] = new Point(r.getX(), r.getY());
    }
}

Munurinn sést þegar punkturinn er færður eftir að þríhyrningurinn er búinn til. Óháða útgáfan af Triangle í geometry-dæminu geymir tilvísanirnar (corners[0] = p;), svo p.shift(3, 1) færir líka horn þríhyrningsins, jafnvel þótt enginn hafi kallað á aðferð þríhyrningsins. Útgáfan sem erfir frá Polygon afritar punktana, svo hún er óháð.

Point p = new Point(1, 1);
Point[] shared = {p, new Point(4, 1), new Point(1, 5)};
Triangle t = new Triangle(shared);   // geymir fylkið sjálft
p.shift(10, 0);
System.out.println(t);
Triangle with points (11.0,1.0) (4.0,1.0) (1.0,5.0)

Þetta er sama tilvísanahugtakið og í kafla 7, bara með hlutum: eigindi sem vísar á hlut deilir hlutnum með öllum öðrum sem hafa tilvísun á hann.

Fylki af hlutum

Card[] hand = new Card[7]; býr til fylki af 7 null-tilvísunum, ekki sjö spil. Hvert spil þarf að búa til með new (eða fá utan frá):

Card[] hand = new Card[7];
hand[0] = new Card(5, 'R');
for (Card c : hand) {
    if (c != null) {                 // annars NullPointerException
        System.out.print(c + " ");
    }
}

Verkefni með mörgum klösum

  • Hver public klasi er í sinni .java-skrá með sama nafni; skrárnar eru í möppu sem heitir eins og pakkinn (package unogame; efst í öllum skránum).
  • Aðeins aðalklasinn hefur main.
  • Á prófinu í Inspera máttu (og þarft stundum að) skrifa marga klasa í sama glugga; þá eru þeir ekki public.
  • Sveigjanleg innri útfærsla, föst ytri viðmót: þú getur breytt því hvernig StackOfCards geymir spilin (fylki, lista) án þess að neinn annar klasi þurfi að breytast, svo lengi sem public aðferðirnar eru þær sömu.

Meira um String

Óbreytanleiki og internering

Strengjabókstafir (literals) með sama innihaldi eru interneraðir: JVM geymir aðeins eitt eintak og allar tilvísanir á "uno" vísa á sama hlutinn. new String("uno") og strengir sem verða til við keyrslu (samskeyting með breytu, nextLine(), substring) eru nýir hlutir:

String a = "uno";
String b = "uno";
String c = new String("uno");
String d = "u";
String e = d + "no";       // búinn til við keyrslu
System.out.println(a == b);
System.out.println(a == c);
System.out.println(a == e);
System.out.println(a.equals(e));
true
false
false
true

Þess vegna virðist == stundum virka á strengi og stundum ekki. Reglan er einföld: alltaf equals.

StringBuilder

Af því að strengir breytast aldrei býr result += x í lykkju til nýjan streng í hverri umferð. StringBuilder er breytanlegur strengur sem er hagkvæmari til að byggja upp texta:

StringBuilder sb = new StringBuilder("uno");
sb.append("!").append(7);    // "uno!7"  (append skilar sama hlutnum)
sb.insert(0, "[");            // "[uno!7"
sb.reverse();                 // "7!onu["
sb.setCharAt(0, '8');         // "8!onu["
String s = sb.toString();

Umbúðaklasar (wrapper classes)

Hvert frumtag á sér klasa: Integer, Double, Character, Boolean… Java breytir sjálfkrafa á milli (autoboxing og unboxing): Integer x = 5; og int y = x;. Þeir hafa líka gagnlegar static aðferðir og fasta: Integer.parseInt, Integer.MAX_VALUE, Double.parseDouble, Character.isDigit.

Samantekt

  • Samband (lína/ör), safntengsl (◇), samsetning (◆), háð (brotin ör), erfðir (▷ heil lína), útfærsla (▷ brotin lína).
  • Fjöldatölur: 1, 0..1, *, 1..*.
  • Eigindi sem vísar á hlut deilir honum; afritaðu ef heildin á að eiga hlutinn sjálf.
  • new Card[7] er sjö null.
  • Strengjabókstafir eru interneraðir; strengir búnir til við keyrslu eru nýir hlutir. Alltaf equals.
  • split, toCharArray, StringBuilder, autoboxing.
