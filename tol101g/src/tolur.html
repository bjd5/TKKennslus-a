Breytur, tölur og inntak

Hér lærir þú að geyma gildi í breytum, reikna með þeim, lesa það sem notandinn slær inn og prenta snyrtilegt svar. Í lokin smíðar þú lánareikni.

Í lok kaflans geturðu

  • valið rétt tag (int, double, String, boolean)
  • reiknað, og forðast gildrurnar í deilingu
  • lesið inntak með Scanner og prentað með printf

1 Breytur

Breyta er hólf með nafni sem geymir gildi. Þú segir hvaða tag gildið hefur, gefur nafn og setur gildi með =.

int age = 20;
age = age + 1;          // nýtt gildi
String name = "Anna";
System.out.println(name + " er " + age);
Anna er 21

Regla: = þýðir „settu í“, ekki „er jafnt og“. age = age + 1 þýðir „taktu gamla gildið, bættu einum við, settu aftur í age“.

Varúð: nafn breytu byrjar á litlum staf og má ekki byrja á tölu: numberOfGuests, ekki 2guests.

3 Fastar: final

final gerir breytu að fasta sem ekki má breyta. Nafnið er í HÁSTÖFUM.

final int MONTHS_IN_YEAR = 12;
final double CAKE_RADIUS = 10;

Hvenær? Fyrir „töfratölur“ sem eiga ekki að breytast: fjöldi reita á borði, fjöldi leikmanna, prósentur.

4 Reikningur

+ - * / eins og venjulega, og % gefur afganginn af deilingu.

System.out.println(10 + 3);
System.out.println(10 / 3);     // heiltala / heiltala
System.out.println(10 % 3);     // afgangur
System.out.println(10.0 / 3);   // ein kommutala → kommusvar
13
3
1
3.3333333333333335

Stærsta gildran: int / int hendir aukastöfunum. 7 / 2 er 3, ekki 3.5. Ef þú vilt kommusvar þarf önnur talan að vera double: 7.0 / 2 eða (double) a / b.

Til hvers er %? Slétt tala: n % 2 == 0. Síðasti tölustafur: n % 10. Mínútur og sekúndur: total / 60 og total % 60.

5 Styttingar: +=, ++ og --

int x = 10;
x += 5;      // x = x + 5
x -= 3;      // x = x - 3
x *= 2;      // x = x * 2
x++;         // x = x + 1
System.out.println(x);
25

Varúð á prófinu: x++ inni í stærri segð notar gamla gildið, ++x nýja. int a = 5; int b = a++; gefur b = 5 og a = 6.

6 Röð aðgerða

Eins og í stærðfræði: svigar, svo * / %, svo + -, frá vinstri til hægri.

System.out.println(2 + 3 * 4);
System.out.println((2 + 3) * 4);
System.out.println(10 - 4 - 3);
14
20
3

7 Breyta á milli taga (cast)

int → double gerist sjálfkrafa. double → int þarftu að biðja um með (int), og þá eru aukastafirnir klipptir af (ekki námundað).

double d = 7.9;
int i = (int) d;
System.out.println(i);
int sum = 7, n = 2;
System.out.println(sum / n);
System.out.println((double) sum / n);
System.out.println(Integer.parseInt("42") + 1);
7
3
3.5
43

Hvenær? (double) sum / n fyrir meðaltal. (int) til að fá heila tölu. Integer.parseInt("42") til að breyta texta í tölu.

9 Snyrtilegar tölur: printf

printf setur gildi inn í texta á stöðum merktum með %.

double price = 1234.5678;
System.out.printf("Verð: %.2f kr%n", price);
System.out.printf("%d spil á hendi%n", 7);
System.out.printf("%s vann!%n", "Anna");
System.out.println(String.format("%.1f", 2.36));
Verð: 1234.57 kr
7 spil á hendi
Anna vann!
2.4

Muna: %d heiltala, %.2f kommutala með 2 aukastöfum, %s texti, %n ný lína. String.format gerir það sama en skilar textanum í stað þess að prenta.

10 Lesa það sem notandinn slær inn

Scanner input = new Scanner(System.in);
System.out.print("Nafn: ");
String name = input.next();
System.out.print("Aldur: ");
int age = input.nextInt();
System.out.print("Hæð: ");

System.out.println();
System.out.println(name + ", " + age + " ára, " + height + " m");

Anna, 20 ára, 1.75 m

(Notandinn sló inn Anna 20 1.75.)

Varúð: efst í skránni þarf import java.util.Scanner;. Og eftir nextInt() skilar nextLine() tómum texta: kallaðu einu sinni á input.nextLine() til að hreinsa.

Á prófinu: ekki prenta „Nafn:“ eða „Enter value:“ nema beðið sé um það.

Verkefni: lánareiknir

Skrifaðu forrit sem les lánsupphæð, ársvexti í % og lánstíma í árum og prentar mánaðarlega afborgun. Formúlan (jafngreiðslulán):

greiðsla = P · r · (1 + r)n / ((1 + r)n − 1)

þar sem P er upphæðin, r mánaðarvextir (ársvextir / 100 / 12) og n fjöldi mánaða (ár · 12).

Skref 1: lestu gildin þrjú.

Skref 2: reiknaðu r og n. Notaðu fasta fyrir 12 og 100.

Skref 3: reiknaðu greiðsluna með Math.pow og prentaðu með %.0f.

final int MONTHS_IN_YEAR = 12;
final int PERCENT = 100;
Scanner input = new Scanner(System.in);
int principal = input.nextInt();
double annualRate = input.nextDouble();
int years = input.nextInt();

double r = annualRate / PERCENT / MONTHS_IN_YEAR;
int n = years * MONTHS_IN_YEAR;
double payment = principal * r * Math.pow(1 + r, n) / (Math.pow(1 + r, n) - 1);
System.out.printf("Mánaðarleg greiðsla: %.0f kr%n", payment);
Mánaðarleg greiðsla: 231545 kr

(Inntak: 30000000 8 25.) Takið eftir að annualRate / PERCENT er kommudeiling því annualRate er double. Ef það væri int fengirðu 0!
