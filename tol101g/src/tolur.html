Tölur, breytur og segðir

Breytur geyma gildi, tög ákveða hvað þær mega geyma og segðir reikna ný gildi. Hér eru reglurnar sem flestar spurningarnar „hvað prentast?“ byggja á: heiltöludeiling, afgangur, forgangur virkja, ++ og --, og hvað gerist þegar tög blandast eða eru kastaðar.

Breytur og tög

Breyta (variable) er nafngreint hólf í minninu. Í Java þarf að lýsa (declare) breytu með tagi (type) áður en hún er notuð, og hún verður að fá gildi (frumstilling, initialization) áður en hún er lesin.

int count;              // yfirlýsing
count = 7;              // gildisveiting (assignment)
double price = 249.5;   // yfirlýsing og frumstilling í einu
final int MAX = 100;    // fasti: má ekki breyta eftir þetta
int a = 1, b = 2;       // tvær breytur í einni yfirlýsingu

= er gildisveiting, ekki jafnaðarmerki: x = x + 1 þýðir „reiknaðu hægri hliðina og settu útkomuna í x“. Samanburður er ==.

Í þessu námskeiði notarðu nánast alltaf int fyrir heiltölur og double fyrir kommutölur. Tala með punkti (2.0) er alltaf double; tala án punkts (2) er int.

Yfirflæði: int hefur endanlegt bil. Integer.MAX_VALUE + 1 verður -2147483648 án nokkurra villuboða. Kommutölur eru nálganir: 0.1 + 0.2 prentast sem 0.30000000000000004, svo berðu aldrei saman double með ==.

Heiltöludeiling stýfir að núlli: kommuhlutanum er hent, ekki námundað. 7 / 2 er 3, -7 / 2 er -3, 1 / 2 er 0. Afgangurinn hefur sama formerki og deilistofninn (vinstri talan), og alltaf gildir (a / b) * b + a % b == a.

% er ótrúlega gagnlegur:

  • n % 2 == 0: er n slétt tala?
  • n % 10: síðasti tölustafurinn; n / 10: talan án síðasta tölustafs.
  • seconds / 60 og seconds % 60: mínútur og sekúndur.
  • player = (player + 1) % PLAYERS: næsti leikmaður, aftur í 0 á eftir þeim síðasta (eins og í Snakes & Ladders).

Forgangur

Eins og í stærðfræði: svigar fyrst, svo * / % (jafn sterk, frá vinstri), svo + - (frá vinstri). Gildisveiting = kemur síðast.

int r = 2 + 3 * 4 % 5 - 6 / 4;
// 3 * 4 = 12,  12 % 5 = 2,  6 / 4 = 1
// 2 + 2 - 1 = 3
System.out.println(r);
3

SkrifaðJafngildir

x++; eða ++x;x = x + 1;

Munurinn á x++ og ++x sést bara þegar gildið er notað í sömu segð:

int x = 5;
int a = x++;   // a fær GAMLA gildið 5, svo verður x 6
int b = ++x;   // x verður 7 FYRST, b fær 7
System.out.println(a + " " + b + " " + x);
5 7 7

Þetta notaði StackOfCards í UNO-spilinu: cards[++top] = card; hækkar top fyrst og geymir svo; return cards[top--]; skilar efsta spilinu og lækkar svo.

Tagabreytingar og kastanir

Þegar int og double blandast í segð er int-gildinu sjálfkrafa breytt í double (víkkun, widening): 5 + 2.0 er 7.0. Sjálfkrafa víkkun fer í þessa átt:

byte → short → int → long → float → double

Í hina áttina (þrenging, narrowing) þarftu að kasta (cast) sjálf(ur), því upplýsingar geta tapast:

double d = 7.9;
int i = (int) d;            // 7  (stýft, ekki námundað)
int j = (int) -7.9;         // -7
double avg = (double) 7 / 2;   // 3.5: kastið gildir um 7, svo deilingin er double-deiling
double bad = (double) (7 / 2); // 3.0: heiltöludeilingin er búin áður en kastað er
int k = 10;
k += 2.7;                   // leyfilegt! += kastar sjálft: k verður 12
// int m = 3.5;             // þýðingarvilla: possible lossy conversion

Kast er sterkara en * / %: (int) 3.7 * 2 er 3 * 2 = 6, en (int) (3.7 * 2) er (int) 7.4 = 7.

Hvernig Java prentar double: heil tala fær alltaf .0 (4.0, ekki 4), og annars eins fáir aukastafir og þarf til að lýsa tölunni nákvæmlega (2.5, 0.1, 3.3333333333333335).

Fullunnið dæmi: sekúndur í mínútur

500 s = 8 mín og 20 s

Samantekt

  • int / int er heiltöludeiling (stýft að núlli); % er afgangur með formerki vinstri hliðar.
  • Forgangur: svigar → kast, ++/-- → * / % → + - → =.
  • x++ notar gamla gildið, ++x nýja.
  • int víkkar sjálfkrafa í double; (int) stýfir.
  • double prentast alltaf með punkti: 7.0.
