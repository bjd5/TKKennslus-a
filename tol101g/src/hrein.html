abstract og interface

Hvert er flatarmál „lögunar“? Það er ekki til fyrr en þú veist hvort hún er hringur eða rétthyrningur. abstract og interface leyfa þér að segja að eitthvað sé hægt, og láta undirklasana segja hvernig.

Í lok kaflans geturðu

  • skrifað hreinan klasa með hreinni aðferð og útfært hana
  • skrifað og útfært viðmót
  • látið Arrays.sort raða þínum eigin hlutum

1 abstract: „undirklasarnir klára“

abstract class Shape {
    public abstract double area();          // engin útfærsla, bara ;
    public String describe() {              // venjuleg aðferð má líka
        return "flatarmál " + area();
    }
}
class Rect extends Shape {
    private double w, h;
    public Rect(double w, double h) { this.w = w; this.h = h; }
    public double area() { return w * h; }
}
class Square extends Rect {
    public Square(double s) { super(s, s); }
}
// í main:
Shape[] shapes = { new Rect(2, 3), new Square(4) };
for (Shape s : shapes) {
    System.out.println(s.describe());
}

  • abstract aðferð hefur enga slaufusviga, bara ;.
  • Það er ekki hægt að gera new Shape(). En Shape s = new Rect(…) er í lagi.
  • Undirklasi verður að útfæra allar abstract-aðferðirnar (eða vera sjálfur abstract).

Hvenær? Þegar yfirklasinn hefur sameiginleg gögn og aðferðir en eitt eða fleiri skref eru ólík fyrir hverja tegund. Úr tímunum: Polygon (abstract calcArea) og Player (abstract playTurn).

2 interface: „getur“

interface Scorable {
    int score();                     // sjálfkrafa public abstract
}
class Card implements Scorable {
    private int n;
    public Card(int n) { this.n = n; }
    public int score() { return n; }
}
class Joker implements Scorable {
    public int score() { return 50; }
}
// í main:
Scorable[] hand = { new Card(7), new Joker(), new Card(2) };
int total = 0;
for (Scorable s : hand) total += s.score();
System.out.println(total);
59

Hvenær? Þegar ólíkir klasar eiga að geta gert sama hlutinn án þess að vera skyldir: spil, nemendur og dagsetningar geta öll verið „samanburðarhæf“.

Varúð: útfærslan verður að vera public (annars þýðingarvilla).

4 Raða þínum hlutum: Comparable

class Card implements Comparable<Card> {
    private int number;
    private char color;
    public Card(int n, char c) { number = n; color = c; }
    public int compareTo(Card other) {
        if (color != other.color) {
            return color - other.color;   // fyrst eftir lit
        }
        return number - other.number;     // svo eftir tölu
    }
    public String toString() { return "" + color + number; }
}
// í main:
Card[] hand = { new Card(7, 'R'), new Card(2, 'G'), new Card(5, 'R') };
Arrays.sort(hand);
System.out.println(Arrays.toString(hand));
[G2, R5, R7]

Reglan fyrir compareTo: skilaðu neikvæðu ef this á að koma á undan, 0 ef jafnt, jákvæðu ef á eftir. Fyrir double: Double.compare(a, b); fyrir texta: name.compareTo(other.name). Öfug röð: víxlaðu (other.x - x).

5 Úr tímanum: Polygon

public abstract class Polygon {
    protected Point[] corners;

    public double calcPerimeter() {                 // eins fyrir alla
        double perimeter = 0;
        for (int i = 0; i < corners.length; i++) {
            perimeter += distance(corners[i], corners[(i + 1) % corners.length]);
        }
        return perimeter;
    }
    public abstract double calcArea();              // ólíkt fyrir hvern
}

Ummálið er reiknað eins fyrir alla marghyrninga (% corners.length tengir síðasta hornið við það fyrsta). Flatarmálið útfæra Triangle og Rectangle hvor á sinn hátt.
