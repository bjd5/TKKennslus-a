Fyrsta Java-forritið

Engin fræði hér: við setjum upp tól, skrifum fyrsta forritið og lærum að prenta á skjáinn. Hver kennslustund er stutt: hvað þetta gerir, kóði, hvað kemur út og hvenær þú notar það.

Í lok kaflans geturðu

  • skrifað og keyrt Java-forrit
  • prentað texta og tölur með println og print
  • lesið villuboð og vitað hvað þau þýða

1 Settu upp tólin

Þú þarft tvennt: JDK (Java sjálft) og ritil (IDE) til að skrifa kóðann í.

  1. Sæktu JDK (t.d. „Temurin“ frá adoptium.net) og settu upp.
  2. Settu upp ritil: NetBeans (notaður í tímunum), IntelliJ IDEA Community eða VS Code með Java-viðbót.
  3. Búðu til nýtt verkefni (New Project → Java). Ritillinn býr til skrá með main fyrir þig.

Ath. Á prófinu skrifar þú í Inspera, sem hefur enga sjálfvirka útfyllingu. Æfðu þig því líka að skrifa kóða án hjálpar.

2 Uppbygging forrits

Öll Java-forrit líta svona út. Lærðu þennan ramma utan að; þú skrifar hann í hvert skipti.

public class Main {                            // klasi: „umbúðirnar“
    public static void main(String[] args) {   // forritið byrjar HÉR
        // kóðinn þinn fer hingað
    }
}
  • public class Main: skráin verður að heita Main.java (sama nafn, sömu hástafir).
  • public static void main(String[] args): alltaf nákvæmlega svona. Hér byrjar keyrslan.
  • { } afmarka hvað á heima saman. Hver { þarf sinn }.
  • Hver skipun endar á ;.

3 Prenta: println og print

System.out.println(…) prentar og fer svo í nýja línu. System.out.print(…) prentar og verður kyrr í sömu línu.

System.out.println("Halló heimur!");
System.out.print("Einn ");
System.out.print("tveir ");
System.out.println("þrír");
System.out.println(42);
Halló heimur!
Einn tveir þrír
42

Hvenær? println nánast alltaf. print þegar þú vilt setja saman eina línu í bútum, t.d. í lykkju.

Varúð: texti er alltaf innan "gæsalappa". Tölur ekki.

4 Texti og tölur saman með +

Plúsinn límir saman texta og gildi. Java les frá vinstri: tölur eru lagðar saman þar til texti birtist, eftir það er allt límt saman.

System.out.println("Aldur: " + 20);
System.out.println(1 + 2 + " spil");
System.out.println("spil " + 1 + 2);
System.out.println("spil " + (1 + 2));
Aldur: 20
3 spil
spil 12
spil 3

Hvenær? Alltaf þegar þú prentar útkomu með skýringu. Settu reikninginn í sviga til að vera örugg(ur).

5 Sérstafir: \n, \t og \"

Inni í texta byrja sérstafir á bakstriki.

System.out.println("Lína 1\nLína 2");
System.out.println("Hann sagði \"hæ\"");
System.out.println("C:\\Users");
Lína 1
Lína 2
Hann sagði "hæ"
C:\Users

7 Hvað gerist þegar þú ýtir á Run?

Tvö skref, á sekúndubroti:

  1. Þýðing (javac): athugar að kóðinn sé löglegur og breytir Main.java í Main.class (bætikóða).
  2. Keyrsla (java, JVM): keyrir bætikóðann. Hann virkar á Windows, Mac og Linux.
