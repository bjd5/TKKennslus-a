Stafir og strengir

Stafir (char) eru tölur í dulargervi og strengir (String) eru hlutir með aðferðum. Hér lærir þú að reikna með stöfum, nota helstu aðferðir String-klasans, bera saman strengi rétt og forsníða úttak með printf.

Tagið char

char geymir einn staf með einföldum gæsalöppum: 'A', '7', ' ', '\n'. Á bak við tjöldin er hver stafur tala (Unicode-kóði). Fyrstu 128 kóðarnir eru þeir sömu og í ASCII:

StafirKóðarAthugið
'0' … '9'48 … 57'7' - '0' er 7 (talan)
'A' … 'Z'65 … 90hástafir á undan lágstöfum
'a' … 'z'97 … 122'a' - 'A' er 32
' ' (bil)32

Af því að char er tala má reikna með honum, en útkoman er int nema þú kastir aftur:

char c = 'a';
System.out.println(c + 1);          // 98   (char + int = int)
System.out.println((char) (c + 1)); // b
c++;                                // ++ og += halda tagi char
System.out.println(c);              // b
System.out.println('a' + 'b');      // 195  (97 + 98, tveir char eru lagðir saman!)
System.out.println("" + 'a' + 'b'); // ab   (strengur fremst: samskeyting)
int digit = '7' - '0';              // 7

Strengir (String)

String er ekki frumtag heldur klasi: strengur er hlutur sem geymir runu af stöfum og hefur aðferðir sem kallað er á með punkti. Stafirnir eru númeraðir frá 0:

String s = "Halló Java";
//          0123456789

Strengir eru óbreytanlegir

Engin String-aðferð breytir strengnum sjálfum; þær skila nýjum streng. Ef þú geymir ekki útkomuna gerist ekkert:

String s = "uno";
s.toUpperCase();          // útkoman glatast
System.out.println(s);
s = s.toUpperCase();      // nú vísar s á nýja strenginn
System.out.println(s);
uno
UNO

Samanburður: equals, ekki ==

== á hlutum spyr hvort þetta sé sami hluturinn í minninu, ekki hvort innihaldið sé eins. Strengur sem er lesinn inn eða búinn til með + eða new er nýr hlutur, svo == getur gefið false þó stafirnir séu þeir sömu. Notaðu alltaf s.equals(t).

compareTo ber saman staf fyrir staf. Við fyrsta stafinn sem er ólíkur skilar hún mismun kóðanna; ef annar strengurinn klárast fyrst skilar hún mismun lengdanna. Hástafir koma á undan lágstöfum ("Z".compareTo("a") er neikvætt).

Strengir og tölur

int n = Integer.parseInt("42");        // strengur → int
double d = Double.parseDouble("2.5");  // strengur → double
String s1 = String.valueOf(42);        // int → strengur
String s2 = "" + 42;                   // sama, með samskeytingu
String s3 = Integer.toString(42);      // sama

Integer.parseInt("4x") kastar NumberFormatException (kafli 12).

Forsniðið úttak: printf og String.format

System.out.printf(snið, gildi…) prentar eftir sniðstreng (án línuskila nema þú setjir %n eða \n). String.format gerir það sama en skilar strengnum.

Fullunnið dæmi: telja sérhljóða og snúa streng við

String s = "Tölvunarfræði";
int vowels = 0;
String reversed = "";
for (int i = 0; i < s.length(); i++) {
    char c = Character.toLowerCase(s.charAt(i));
    if ("aáeéiíoóuúyýæö".indexOf(c) >= 0) {
        vowels++;
    }
    reversed = c + reversed;     // nýr stafur fremst
}
System.out.println(vowels + " " + reversed);
5 iðærfranuvlöt

(Lykkjur koma í kafla 5; hér skiptir máli mynstrið for (int i = 0; i < s.length(); i++) og s.charAt(i).)

Samantekt

  • char er tala: 'a' + 1 er 98, (char) ('a' + 1) er 'b', '7' - '0' er 7.
  • Strengir eru númeraðir frá 0; substring(b, e) tekur ekki staf nr. e með.
  • indexOf skilar −1 ef ekkert finnst.
  • Strengir breytast aldrei: s = s.toUpperCase();
  • equals fyrir innihald, aldrei ==; compareTo fyrir röð.
  • %d %.2f %s %5d %-5s í printf.
