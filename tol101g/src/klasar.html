Klasar: búðu til þín eigin tög

Hingað til hefur þú notað tög sem Java á (int, String, Scanner). Nú býrðu til þín eigin: Card, Player, Circle. Héðan í frá færumst við nær áfanganum og notum UNO-spilið úr tímunum.

Í lok kaflans geturðu

  • skrifað klasa með eigindum, smið, get/set og toString
  • búið til hluti með new og kallað á aðferðir þeirra
  • vitað hvenær á að nota this, private og static

1 Hvenær býrðu til klasa?

Þegar mörg gildi eiga saman. Spil hefur tölu og lit. Í stað tveggja fylkja (int[] numbers, char[] colors) býrðu til eitt tag, Card, og hvert spil verður einn hlutur.

Klasi = uppskriftin (hvaða gögn og aðgerðir spil hefur).

Hlutur = eitt raunverulegt spil, búið til með new.

2 Klasinn Card

class Card {
    private int number;            // eigindi: gögn hvers spils
    private char color;

    public Card(int number, char color) {   // smiður
        this.number = number;
        this.color = color;
    }
    public int getNumber() { return number; }   // getter
    public char getColor() { return color; }

    public boolean matches(Card other) {        // aðgerð
        return number == other.number || color == other.color;
    }
    public String toString() {
        return "" + color + number;
    }
}
// í main:
Card a = new Card(7, 'R');
Card b = new Card(7, 'G');
Card c = new Card(2, 'Y');
System.out.println(a);
System.out.println(a.matches(b) + " " + a.matches(c));
System.out.println(b.getColor());

3 this

this = „þessi hlutur“. Þú þarft það þegar færibreytan heitir það sama og eigindið:

public Card(int number, char color) {
    this.number = number;   // eigindið = færibreytan
}

Algeng villa: number = number; án this gerir ekkert; eigindið verður 0. (Prófspurning!)

4 Setter sem passar upp á gildið

class Circle {
    private double r;
    public Circle(double r) {
        setR(r);
    }
    public void setR(double r) {
        if (r < 0) {
            r = -r;            // enginn neikvæður radíus
        }
        this.r = r;
    }
    public double getR() { return r; }
    public double area() { return Math.PI * r * r; }
}
// í main:
Circle c = new Circle(-2);
System.out.println(c.getR());
c.setR(1);
System.out.printf("%.2f%n", c.area());

3.14

Af hverju private + setter? Svo enginn geti sett rugl í hlutinn. Setterinn ákveður hvað er löglegt. Ef gildi á aldrei að breytast (eins og litur spils): enginn setter.

5 Hlutir eru vísanir (eins og fylki)

class Counter {
    private int value;
    public void inc() { value++; }

6 static: tilheyrir klasanum, ekki hlutnum

class Player {
    private static int count = 0;   // EITT fyrir alla
    private String name;            // eitt á hvern leikmann
    public Player(String name) {
        this.name = name;
        count++;
    }
    public static int getCount() { return count; }
}
// í main:
new Player("Anna");
new Player("Kári");
System.out.println(Player.getCount());
2

Hvenær static? Fyrir það sem er sameiginlegt öllum (teljari, fasti) og hjálparaðferðir sem þurfa engan hlut (eins og Math.max). Annars: ekki static.

Algeng villa: að kalla á aðferð án static beint úr main („non-static … cannot be referenced from a static context“). Búðu fyrst til hlut með new.

7 Úr tímanum: StackOfCards

Bunki af spilum: síðasta spilið sem fer á er það fyrsta sem kemur af (eins og raunverulegur bunki). Fylki + vísir á efsta spilið:

class StackOfCards {
    private Card[] cards = new Card[112];
    private int top = -1;                   // -1 = tómur

    public void push(Card card) { cards[++top] = card; }   // hækka, svo setja
    public Card pop()           { return cards[top--]; }   // taka, svo lækka
    public Card peek()          { return cards[top]; }
    public boolean isEmpty()    { return top == -1; }
}

8 Klasi í UML (á prófinu)

Card
──────────────────────────
- number : int
- color : char
──────────────────────────
+ Card(number : int, color : char)
+ getNumber() : int
+ matches(other : Card) : boolean
+ toString() : String

- = private, + = public. Tagið kemur á eftir nafninu með tvípunkti. Á prófinu þarftu að geta breytt þessu í Java og öfugt: - number : int → private int number;, + getNumber() : int → public int getNumber().

Prófaðu: skrifaðu klasann BankAccount með private balance, deposit(double), withdraw(double) sem skilar false ef innistæðan dugar ekki, og getBalance(). (Lausnin er í kóðaskrifunum.)
