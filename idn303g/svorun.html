Tímasvörun og tíðnisvörun

Kaflar 12-13 í heftinu (vika 4-5). Spurning 1 á lokaprófinu er alltaf af þessu tagi: gefin er diffurjafna, finna á yfirfærslufallið og lýsa þrepasvöruninni. Hér eru pólar, kerfi fyrstu og annarrar gerðar, tíðnisvörun og Bode-rit.

Pólar í s-planinu

Pólar (rætur nefnarans í $G(s)$, þ.e. rætur kennijöfnunnar) ráða svipulu svöruninni, þ.e. hvernig kerfið bregst við þar til jafnvægi næst.

Kippsvörun ($u = \delta(t)$, $U(s) = 1$) er einfaldlega $g(t) = \mathcal L^{-1}[G(s)]$. Við þrepafall bætist sístæða svörunin (jafnvægið) við svipulu svörunina.

Kerfi fyrstu gerðar

$$\dot y + ay = bu \quad\Longrightarrow\quad G(s) = \frac{b}{s+a} = \frac{K}{\tau s + 1},\qquad K = \frac{b}{a},\quad \tau = \frac1a$$ $$\text{Þrepasvörun: } y(t) = K\bigl(1 - e^{-t/\tau}\bigr)\qquad \text{Kippsvörun: } y(t) = b\,e^{-at}$$

Tveir stikar lýsa svöruninni: jafnvægisgildið $K = G(0)$ (lokagildisreglan $\lim_{t\to\infty}y = \lim_{s\to0}sY(s)$) og tímastuðullinn $\tau$. Póllinn er í $s = -1/\tau$.

Kerfi annarrar gerðar

$$\ddot y + a_1\dot y + a_2y = bu \quad\Longrightarrow\quad G(s) = \frac{K\omega_n^2}{s^2 + 2\zeta\omega_ns + \omega_n^2},\qquad \omega_n = \sqrt{a_2},\quad \zeta = \frac{a_1}{2\omega_n},\quad K = \frac{b}{a_2}$$ $$p_{1,2} = -\zeta\omega_n \pm j\omega_n\sqrt{1-\zeta^2}$$

$\zeta$ er dempunarhlutfall og $\omega_n$ náttúruleg tíðni. Ef stuðullinn við $\ddot y$ er ekki 1, deildu fyrst í gegn með honum.

Uppskrift fyrir spurningu 1

  1. Laplace með núll-upphafsskilyrðum: $y' \to sY$, $y'' \to s^2Y$. Einangra $G(s) = Y/U$.
  2. Jafnvægisgildi: $K = G(0)$.
  3. Gerð kerfisins: stig nefnarans. Finndu pólana.
  4. Fyrstu gerðar: skrifa $\dfrac{K}{\tau s+1}$ og lesa $\tau$. Taka fram að $\zeta$, $\omega_n$, $T_p$ og $M_p$ eiga ekki við (ekkert yfirskot, ein raunrót).
  5. Annarrar gerðar: deila í gegn svo stuðullinn við $s^2$ sé 1. $\omega_n = \sqrt{a_2}$, $\zeta = a_1/(2\omega_n)$, $\tau = 1/(\zeta\omega_n)$. Ef $\zeta < 1$: reikna $T_p$ og $M_p$. Ef $\zeta \ge 1$: ekkert yfirskot, tveir tímastuðlar ($-1/p_1$, $-1/p_2$) og sá stærri ræður.
  6. Tími í jafnvægi: um $4\tau$ (stærsta $\tau$).

Dæmi: lokaprófin 2025 S1 ($2y'+5y=u$, fyrstu gerðar) og 2024 S1 ($y''+2y'+2y=u$, annarrar gerðar) eru leyst skref fyrir skref.

Þrepasvörun

Bode-rit

mögnunfasi

Taktu eftir: lítið $\zeta$ gefur háan topp í mögnuninni (ómun) og mikið yfirskot í tímasvöruninni. Við $\zeta \ge 1/\sqrt2 \approx 0{,}707$ hverfur toppurinn í Bode-ritinu.

Kerfi hærri gerðar

Með stofnbrotaliðun má skrifa svörun kerfis hærri gerðar sem summu af svörun kerfa fyrstu og annarrar gerðar, t.d.

$$G(s) = \frac{K\omega_n^2}{(\tau s+1)(s^2+2\zeta\omega_ns+\omega_n^2)} = \frac{k_1}{\tau s+1} + \frac{k_{21}s + k_{22}}{s^2+2\zeta\omega_ns+\omega_n^2}$$
  • Jafnvægisgildið fæst eins og áður: $K = G(0)$.
  • Tímalengd svipulu svörunarinnar ræðst af lengsta tímastuðlinum (pólnum næst $j\omega$-ásnum), ef hann hefur umtalsverð áhrif.
  • Núll (rætur teljarans) breyta ekki stöðugleika en geta valdið yfirskoti, jafnvel þótt allir pólar séu raunrætur. Dæmi 12.5.1 (l) hér að neðan.
  • Rístíma og yfirskot er erfiðara að lesa beint; þar hjálpar tíðnisvörunin.

Tíðnisvörun

Ef inntakið er sínusbylgja kemur fram sínusbylgja af sömu tíðni í úttakinu (eftir að svipula svörunin er horfin), mögnuð og hliðruð:

$$u(t) = A\cos(\omega t) \quad\Longrightarrow\quad y(t) = A\,|G(j\omega)|\cos\bigl(\omega t + \varphi\bigr),\qquad \varphi = \angle G(j\omega)$$

Tíðnisvörunarfallið er $G(j\omega)$: settu $s = j\omega$. Neikvætt $\varphi$ þýðir að úttakið er á eftir inntakinu. Þar sem flest merki eru summa sínusbylgja (Fourier) lýsir $G(j\omega)$ hvaða tíðnir komast í gegn, t.d. hvernig truflanir deyfast.

Fyrstu gerðar

$$G(j\omega) = \frac{K}{1 + j\tau\omega},\qquad |G| = \frac{K}{\sqrt{1+\tau^2\omega^2}},\qquad \varphi = -\arctan(\tau\omega)$$
  • Mögnun: lárétt aðfella $20\log K$ dB upp að $\omega = 1/\tau$, svo lína með halla −20 dB/dec. Í $\omega = 1/\tau$ er raungildið 3 dB undir aðfellunni.
  • Bandvídd $\omega_B = 1/\tau$: minni $\tau$ gefur meiri bandvídd og hraðari svörun.
  • Fasi: 0° upp að um $0{,}1/\tau$, −45° í $1/\tau$, −90° frá um $10/\tau$.

Annarrar gerðar

$$|G(j\omega)| = \frac{K}{\sqrt{\bigl(1-(\omega/\omega_n)^2\bigr)^2 + \bigl(2\zeta\omega/\omega_n\bigr)^2}},\qquad \varphi = -\arctan\frac{2\zeta\,\omega/\omega_n}{1-(\omega/\omega_n)^2}$$
  • Mögnun: lárétt $20\log K$ upp að $\omega_n$, svo −40 dB/dec.
  • Ómun fyrir $\zeta \le 1/\sqrt2$: hámark $M_r = \dfrac{K}{2\zeta\sqrt{1-\zeta^2}}$ við $\omega_r = \omega_n\sqrt{1-2\zeta^2}$. Gróf nálgun: toppur $K/(2\zeta)$ í $\omega_n$. Fyrir $\zeta > 1/\sqrt2$ er enginn toppur.
  • Fasi: 0° → −90° í $\omega_n$ → −180°. Bandvídd um $\omega_n$ (nákvæmlega $\omega_n$ þegar $\zeta = 1/\sqrt2$).

Að rissa Bode-rit

  1. Skrifa $G$ sem margfeldi þátta á formunum $K$, $s^{\pm1}$, $(1+Ts)^{\pm1}$, annarrar gerðar og $e^{-Ls}$.
  2. Mögnun í dB leggst saman ($20\log|G_1G_2| = 20\log|G_1| + 20\log|G_2|$) og fasarnir leggjast saman.
  3. Byrja vinstra megin: lágtíðnihallinn er $-20N$ dB/dec, þar sem $N$ er fjöldi heilda. Við hverja hornatíðni ($1/T$ eða $\omega_n$) breytist hallinn um ∓20 (eða ∓40) dB/dec.

Dæmi 13.1.1 Tíðnisvörunarföll

Finnið $|G(j\omega)|$ og $\varphi(\omega)$ fyrir: (a) $\dfrac{4}{s}$   (b) $\dfrac{10}{s(1+3s)}$   (c) $\dfrac{e^{-3s}}{1+2s}$   (d) $\dfrac{e^{-2s}}{(1+3s)(5+s)}$   (e) $\dfrac{2}{1+0{,}4s+2s^2}$

(a) $|G| = \dfrac{4}{\omega}$, $\varphi = -90^\circ$.

(b) $|G| = \dfrac{10}{\omega\sqrt{1+9\omega^2}}$, $\varphi = -90^\circ - \arctan(3\omega)$.

(c) $|G| = \dfrac{1}{\sqrt{1+4\omega^2}}$ (seinkunin breytir ekki mögnuninni), $\varphi = -3\omega\ \mathrm{rad} - \arctan(2\omega)$.

(d) $|G| = \dfrac{1}{\sqrt{1+9\omega^2}\,\sqrt{25+\omega^2}}$, $\varphi = -2\omega\ \mathrm{rad} - \arctan(3\omega) - \arctan(\omega/5)$.

(e) $|G| = \dfrac{2}{\sqrt{(1-2\omega^2)^2 + (0{,}4\omega)^2}}$, $\varphi = -\arctan\dfrac{0{,}4\omega}{1-2\omega^2}$ (bætir við −180° þegar $\omega > 1/\sqrt2$). Hér er $K = 2$, $\omega_n = 1/\sqrt2 = 0{,}707$ rad/s og $\zeta = 0{,}141$, svo kerfið hefur skarpan ómunartopp: $M_r = \dfrac{2}{2\cdot0{,}141\sqrt{1-0{,}02}} = 7{,}14$ (17 dB) við $\omega_r = 0{,}693$ rad/s.
