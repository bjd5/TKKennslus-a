Líkanagerð

Kaflar 4-9 í heftinu (vika 2-3). Spurning 2 á lokaprófinu er alltaf líkanagerð: vatnstankur 2024 og rafrás 2025. Hér er aðferðin, grunneiningar hverrar tegundar kerfis og dæmi.

Hvað er líkan?

Líkan er verkfæri til að svara spurningum um hegðun kerfis án þess að gera tilraunir á því: þegar tilraunir eru of dýrar eða hættulegar, eða áður en kerfið er til. Í námskeiðinu eru líkönin

Slík líkön eru línulegar diffurjöfnur með fastastuðlum: $y^{(n)} + a_1y^{(n-1)} + \dots + a_ny = b_0u^{(n)} + \dots + b_nu$. Þær má líka skrifa sem ástandslíkan $\dot{\mathbf x} = A\mathbf x + B u$, $y = C\mathbf x$, en á prófunum er ekki beðið um ástandsform.

Tvær leiðir að líkani

Út frá náttúrulögmálum (physical modeling):

  1. Afmörkun og uppskipting: hvað er kerfið, hverjar eru einingarnar, inntak og úttak? (Markmið líkansins ræður.)
  2. Grunnjöfnur: lögmál fyrir hverja einingu (Newton, Kirchhoff, massa- og orkujafnvægi).
  3. Diffurjafna fyrir kerfið í heild: eyða innri breytum.

Út frá mælingum (system identification):

  1. Afmörkun og uppskipting (eins).
  2. Koma kerfinu í vinnupunkt, breyta inntaki (t.d. þrep) og mæla úttakið þar til nýtt jafnvægi næst.
  3. Meta diffurjöfnu og stika ($K$, $\tau$, ...) út frá mælingunum.

Seinni leiðin var notuð í hönnunarverkefninu: þrepasvörun hitastigs mæld og $K$ og $\tau$ lesin af henni (sjá tímasvörun).

Vinnupunktur og línuleg nálgun

Fá raunveruleg kerfi eru línuleg. Lausnin er að gera líkan af frávikum frá vinnupunkti (jafnvægi) og nálga með fyrsta stigs Taylor-margliðu: $\hat f(x) = f(x_0) + f'(x_0)(x - x_0)$.

Dæmi (vatnstankur, kafli 4): $A\dfrac{dh}{dt} = v - q$ og útflæðið fylgir Bernoulli, $q = a\sqrt{2gh}$, sem er ólínulegt. Í jafnvægi er $q_0 = v_0$ og $h_0 = \frac{1}{2g}\bigl(\frac{v_0}{a}\bigr)^2$. Línulega nálgunin er $\hat q = q_0 + a\sqrt{\tfrac{g}{2h_0}}\,(h - h_0)$ og þá fæst

$$T\frac{d\hat q}{dt} + \hat q = v,\qquad T = \frac{A}{a}\sqrt{\frac{2h_0}{g}}$$

Afleiðingar: stikarnir (hér $T$) eru háðir vinnupunktinum, og líkanið verður ónákvæmara eftir því sem frávikið er stærra. Í lokaprófinu 2024 S2 er línulega nálgunin gefin: „nálægt $h_0$ má gera ráð fyrir $q_2 = h/R$“.

Vélar (kafli 5)

Hreyfing eftir línu (inntak $F$, úttak $x$)

$$F = kx,\qquad F = c\,\frac{dx}{dt},\qquad F = m\,\frac{d^2x}{dt^2}$$

Orka: fjöður $\tfrac12kx^2$, massi $\tfrac12mv^2$; dempari tapar aflinu $cv^2$.

Snúningur (inntak $\tau$, úttak $\theta$)

$$\tau = k\theta,\qquad \tau = c\,\omega,\qquad \tau = I\,\frac{d^2\theta}{dt^2}$$

Orka: $\tfrac12k\theta^2$, $\tfrac12I\omega^2$; tap $c\omega^2$.

Aðferð: teiknaðu alla krafta sem verka á hvern massa og notaðu $\sum F = ma$. Massi, fjöður og dempari tengd vegg (mynd 5.2):

$$F - kx - c\dot x = m\ddot x \quad\Longrightarrow\quad \ddot x + \frac{c}{m}\dot x + \frac{k}{m}x = \frac{F}{m}$$

Ef massarnir eru fleiri er sett upp kraftajafnvægi fyrir hvern þeirra og jöfnurnar sameinaðar.

Rafrásir (kafli 6)

$$v = Ri,\qquad i = C\,\frac{dv}{dt},\qquad v = L\,\frac{di}{dt}$$

Orka: þéttir $\tfrac12Cv^2$, spóla $\tfrac12Li^2$; viðnám tapar $P = vi = v^2/R$.

Lögmál Kirchhoffs: (1) straumur inn í hnút = straumur út úr honum; (2) í lokaðri lykkju er summa spennufalla jöfn spennunni sem fæðir hana.

RLC í röð, úttak er spennan yfir þéttinn: $v = Ri + L\dfrac{di}{dt} + v_C$ og $i = C\dfrac{dv_C}{dt}$ gefa

$$\frac{d^2v_C}{dt^2} + \frac{R}{L}\frac{dv_C}{dt} + \frac{1}{LC}v_C = \frac{1}{LC}v$$

Sams konar jafna og massi-fjöður-dempari: $L \leftrightarrow m$, $R \leftrightarrow c$, $1/C \leftrightarrow k$.

RC-rás (viðnám í röð, þéttir yfir úttakið): $RC\,\dot y + y = u$, fyrstu gerðar með $\tau = RC$.

Straumefni (kafli 7)

Vökvaviðnám (loki, þrenging): $p_1 - p_2 = Rq$

Vökvarýmd (tankur): $q_1 - q_2 = A\dfrac{dh}{dt} = C\dfrac{dp}{dt}$, $C = \dfrac{A}{\rho g}$, $p = \rho gh$

Vökvatregða (pípa, lengd $L$): $p_1 - p_2 = I\dfrac{dq}{dt}$, $I = \dfrac{L\rho}{A}$

Loft (samþjappanlegt, massaflæði $q_m$): $p_1 - p_2 = Rq_m$, $q_{m1} - q_{m2} = C\dfrac{dp}{dt}$ með $C = \rho\dfrac{dV}{dp} + \dfrac{VM}{R_gT}$ (gasjafnan $pV = \frac{m}{M}R_gT$).

Tankur með loka, tregða óveruleg: $q_1 - q_2 = C\dfrac{dp}{dt}$ og $p = Rq_2$ gefa $RC\,\dfrac{dq_2}{dt} + q_2 = q_1$. Með tregðu fæst annarrar gerðar jafna (7.22), sem jafngildir RLC-rás.

Tvær ritvenjur fyrir viðnám. Í heftinu er $R$ skilgreint út frá þrýstingi ($p = Rq$, eining Pa·s/m³), og þá er $\tau = RC = RA/(\rho g)$. Í lokaprófinu 2024 er $R$ skilgreint út frá hæð ($q_2 = h/R$, eining s/m²), og þá er $\tau = AR$. Notaðu skilgreininguna sem er gefin í dæminu og athugaðu einingarnar.

Varmi (kafli 8)

Varmaviðnám: $q = \dfrac{T_1 - T_2}{R}$, með $R = \dfrac{L}{Ak}$ fyrir varmaleiðni og $R = \dfrac{1}{Ah}$ fyrir varmaburð.

Varmarýmd: $q_1 - q_2 = C\dfrac{dT}{dt}$, $C = mc$ (massi × eðlisvarmi, J/°C).

Hitamælir í vökva með hitastig $T_L$: $\dfrac{T_L - T}{R} = C\dfrac{dT}{dt}$, svo $RC\,\dot T + T = T_L$. Hitanemi er því fyrstu gerðar með $\tau = RC$, sem er einmitt líkanið af nemum í kaflanum um nema.

Gegnumstreymistankur (flæði $q$, rúmmál $V$, hitari $P$): orkujafnvægi $\rho c V\dot T_2 = \rho cq(T_1 - T_2) + P$, svo $\dfrac{V}{q}\dot T_2 + T_2 = T_1 + \dfrac{P}{\rho cq}$ og $\tau = V/q$ (könnun 2020 S3).

Uppskrift fyrir spurningu 2

  1. Jafnvægisjafna fyrir geymsluna: massajafnvægi (tankur), orkujafnvægi (varmi), $\sum F = ma$ (vélar) eða Kirchhoff (rafrásir).
  2. Grunnjöfnur fyrir hverja einingu ($q = h/R$, $i = C\,dv/dt$, $F = kx$, ...).
  3. Eyða innri breytum og raða á staðalformið $\tau\dot y + y = Ku$ (eða annarrar gerðar).
  4. Lesa af: $\tau$ og $K$. Jafnvægi: setja allar afleiður = 0. Tími í jafnvægi: $4\tau$.
  5. Athuga einingar og hvort jafnan lýsir frávikum frá vinnupunkti.

Dæmi úr heftinu

Dæmi 6.1.6 Spennudeilir með þétti

Inntaksspennan $u$ fer í gegnum $R_1$ að hnút. Frá hnútnum til jarðar liggja $R_2$ og þéttirinn $C$ hliðtengd. Úttakið $y$ er spennan yfir þéttinn. Finnið jöfnu sem tengir $u$ og $y$.

Kirchhoff í hnútnum: $\dfrac{u - y}{R_1} = \dfrac{y}{R_2} + C\dot y$. Margföldum með $R_1$:

$$R_1C\,\dot y + \Bigl(1 + \frac{R_1}{R_2}\Bigr)y = u \quad\Longrightarrow\quad \frac{R_1R_2C}{R_1+R_2}\,\dot y + y = \frac{R_2}{R_1+R_2}\,u$$

$\tau = (R_1\parallel R_2)\,C$ og $K = R_2/(R_1+R_2)$. Þetta er nákvæmlega rásin í lokaprófinu 2025 S2 eftir að rofinn opnast.

Dæmi 8.1.1 Ofn

Ofn er hitaður með varmaflæðinu $P$. Hitinn inni í ofninum er $T_1$ og fyrir utan $T_2$. Veggurinn hefur varmaviðnám $R$ og ofninn varmarýmd $C$. Finnið jöfnu fyrir $T_1$.

Orkujafnvægi: varmi inn mínus varmi út = $C\dot T_1$:

$$P - \frac{T_1 - T_2}{R} = C\frac{dT_1}{dt} \quad\Longrightarrow\quad RC\,\dot T_1 + T_1 = RP + T_2$$

$\tau = RC$. Í jafnvægi er $T_1 = T_2 + RP$: hitinn hækkar um $RP$ umfram umhverfið.

Dæmi 7.3.1 Tveir tankar

Jafnt flæði $Q$ rennur inn í vinstri tankinn. Á milli tankanna (báðir með flatarmál $A$) er loki með viðnám $R$; flæðið á milli er $q = (h_1 - h_2)/R$ (hæðarvenja). Hægri tankurinn hefur ekkert annað útflæði. Finnið jöfnu fyrir $h_2$ fyrir gefið $h_1$.

Massajafnvægi hægri tanks: $A\dot h_2 = q = \dfrac{h_1 - h_2}{R}$, svo

$$AR\,\dot h_2 + h_2 = h_1$$

Fyrstu gerðar með $\tau = AR$ og mögnun 1: hæðin í hægri tanknum eltir hæðina í þeim vinstri. (Með $p = Rq$ venju heftisins verður $\tau = AR/(\rho g)$.)

Fleiri dæmi með lausnum: vatnstankur 2024 S2, RC-rás 2025 S2, massi og fjaðrir og varmi í könnun 2020. Æfðu þig með slembitölum í æfingaspurningunum (flokkur „Líkanagerð“).
