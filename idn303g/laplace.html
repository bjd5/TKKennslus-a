Diffurjöfnur, Laplace og blokkrit

Kaflar 10-11 í heftinu (vika 4). Laplace-vörpun breytir diffurjöfnu í margliðujöfnu: þannig fæst yfirfærslufallið í spurningu 1 á lokaprófinu, og blokkritsreglurnar eru notaðar í spurningu 4.

Lausnir á diffurjöfnum: hefðbundin leið

Almenn lausn er $y = y_h + y_p$: almenn lausn óhliðruðu jöfnunnar (hægri hlið = 0) plús ein sérlausn hliðruðu jöfnunnar. Fastarnir ráðast af upphafsskilyrðum. Hér er inntakið einingarþrep og kerfið í hvíld í upphafi.

Fyrstu gerðar: $y' + ay = bu$, $y(0) = 0$:

$$y_h = Ce^{-at},\quad y_p = \frac ba \quad\Longrightarrow\quad y(t) = \frac ba\bigl(1 - e^{-at}\bigr)$$

Annarrar gerðar: $y'' + a_1y' + a_2y = bu$, $y(0) = y'(0) = 0$. Útlitið ræðst af rótum kennijöfnunnar $r^2 + a_1r + a_2 = 0$, $p_{1,2} = \dfrac{-a_1 \pm \sqrt{a_1^2 - 4a_2}}{2}$. Sérlausnin er $y_p = b/a_2$.

Laplace-vörpun

$$F(s) = \mathcal L[f(t)] = \int_0^\infty f(t)\,e^{-st}\,dt,\qquad s = \sigma + j\omega$$

Vörpunin færir fallið úr tímarúmi yfir í tvinntölurúmið (s-rúmið). Í reynd er andhverfan aldrei reiknuð með heildi heldur lesin úr töflu.

Uppskrift: diffurjafna leyst með Laplace

  1. Varpa báðum hliðum (diffrun verður margföldun með $s$; upphafsgildi 0).
  2. Einangra $Y(s)$ og setja inn inntakið, t.d. $U(s) = 1/s$ fyrir þrep.
  3. Stofnbrotaliða $Y(s)$.
  4. Lesa hvern lið úr töflunni og leggja saman.
  5. Prófa: $y(0)$ og $y(\infty) = \lim_{s\to0} sY(s)$.

Stofnbrotaliðun

Ólíkar rætur $p_i$: $Y = \dfrac{k_1}{s-p_1} + \dots + \dfrac{k_n}{s-p_n}$ með

$$k_i = (s - p_i)\,Y(s)\big|_{s=p_i}$$

Margföld rót $p$ (margfeldni $r$): $Y = \dfrac{k_{p1}}{s-p} + \dots + \dfrac{k_{pr}}{(s-p)^r}$ með $k_{pi} = \dfrac{1}{(r-i)!}\dfrac{d^{\,r-i}}{ds^{\,r-i}}\bigl[(s-p)^rY(s)\bigr]_{s=p}$. Fyrir tvöfalda rót: $k_{p2} = (s-p)^2Y|_{s=p}$ og $k_{p1} = \frac{d}{ds}\bigl[(s-p)^2Y\bigr]_{s=p}$.

Samoka tvinnrætur $\sigma \pm j\omega$: skrifa liðinn sem $\dfrac{k_1(s-\sigma) + k_2\omega}{(s-\sigma)^2 + \omega^2}$, margfalda $Y$ með $(s-\sigma)^2 + \omega^2$, setja $s = \sigma + j\omega$ og leysa fyrir raun- og þverhluta. Liðirnir verða $k_1e^{\sigma t}\cos\omega t + k_2e^{\sigma t}\sin\omega t$. Sjá dæmi í könnun 2020, spurningu 2.

Yfirfærsluföll (kafli 11)

Ef kerfi er lýst með $y^{(n)} + a_1y^{(n-1)} + \dots + a_ny = b_1u^{(n-1)} + \dots + b_nu$ og er í hvíld í upphafi, þá er yfirfærslufallið

$$G(s) = \frac{Y(s)}{U(s)} = \frac{b_1s^{n-1} + \dots + b_n}{s^n + a_1s^{n-1} + \dots + a_n}$$
  • Yfirfærslufallið lýsir kerfinu óháð inntakinu: $Y(s) = G(s)U(s)$.
  • Pólar eru rætur nefnarans (= rætur kennijöfnunnar) og ráða svipulu svöruninni og stöðugleika. Núllstöðvar eru rætur teljarans.
  • $G(s)$ er líka Laplace-vörpun kippsvörunarinnar, því $\mathcal L[\delta] = 1$.
  • Jafnvægisgildi þrepasvörunar er $G(0)$ (ef kerfið er stöðugt).

Véleindakerfi með truflun (myndir 11.3-11.5)

Líkanið er línulegt, svo áhrif inntaks og truflunar má reikna sitt í hvoru lagi og leggja saman (samlagningarreglan):

$$Y(s) = \underbrace{\frac{SHV}{1 + SHVN}}_{G(s)}\,U(s) + \underbrace{\frac{V}{1 + HSN}}_{G_R(s)}\,R(s)$$

Til að finna $G_R$ er $U$ sett = 0: frá $R$ er framleiðin bara $V$, en lykkjan er sú sama. Bæði föllin hafa því sama nefnara $1 + SHVN$, sem er ástæða þess að yfirfærslufall lykkjunnar $G_K = SHVN$ ræður öllum eiginleikum kerfisins (sjá sjálfvirk stýrikerfi).

Dæmi úr heftinu

Dæmi 10.4.3 (c) Andhverf vörpun

Finnið andhverfu Laplace-vörpunina af $Y(s) = \dfrac{5s+12}{s^2+5s+6}$.

$s^2 + 5s + 6 = (s+2)(s+3)$, svo $Y = \dfrac{k_1}{s+2} + \dfrac{k_2}{s+3}$:

$$k_1 = \frac{5s+12}{s+3}\Big|_{s=-2} = \frac{2}{1} = 2,\qquad k_2 = \frac{5s+12}{s+2}\Big|_{s=-3} = \frac{-3}{-1} = 3$$

$y(t) = $ $2e^{-2t} + 3e^{-3t}$. Prófun: $y(0) = 5 = \lim_{s\to\infty} sY(s)$ ✓.

Dæmi 10.4.4 (d) Tvær raunrætur

Leysið $y'' + 6y' + 8y = 3u$ með Laplace, $u$ einingarþrep og kerfið í hvíld.

$$Y(s) = \frac{3}{s(s^2+6s+8)} = \frac{3}{s(s+2)(s+4)} = \frac{k_1}{s} + \frac{k_2}{s+2} + \frac{k_3}{s+4}$$

$k_1 = \dfrac{3}{2\cdot4} = \dfrac38$, $\;k_2 = \dfrac{3}{(-2)(2)} = -\dfrac34$, $\;k_3 = \dfrac{3}{(-4)(-2)} = \dfrac38$.

$$y(t) = \frac38 - \frac34e^{-2t} + \frac38e^{-4t}$$

Prófun: $y(0) = \frac38 - \frac68 + \frac38 = 0$ ✓, $y(\infty) = \frac38 = G(0)$ ✓.

Dæmi 10.4.4 (a) Ódempað kerfi

Leysið $y'' + 16y = u$ með Laplace, $u$ einingarþrep og kerfið í hvíld.

$Y(s) = \dfrac{1}{s(s^2+16)}$. Beint úr töflunni ($a = 4$):

$$y(t) = \frac{1}{16}\bigl(1 - \cos 4t\bigr)$$

Pólarnir $\pm4j$ liggja á $j\omega$-ásnum: engin dempun, svo úttakið sveiflast endalaust á milli 0 og $1/8$ og nær aldrei jafnvægi. Lokagildisreglan gildir ekki hér.

Dæmi 11.1.1 (c) og (d) Yfirfærsluföll

Finnið yfirfærslufallið fyrir (c) $y'' - 3y' + 2y = 3u' + u$ og (d) $y'' + 3y' + 2y - u' + 3u = 0$.

(c) $(s^2 - 3s + 2)Y = (3s + 1)U$:

$$G(s) = \frac{3s+1}{s^2 - 3s + 2} = \frac{3s+1}{(s-1)(s-2)}$$

Pólarnir eru $s = 1$ og $s = 2$, báðir í hægra hálfplani: kerfið er óstöðugt.

(d) Færum $u$-liðina yfir: $y'' + 3y' + 2y = u' - 3u$, svo

$$G(s) = \frac{s-3}{s^2 + 3s + 2} = \frac{s-3}{(s+1)(s+2)}$$

Pólar $-1$ og $-2$ (stöðugt), núllstöð í $s = 3$. Gættu að formerkjunum þegar inntaksliðirnir eru vinstra megin.

Dæmi Einföldun blokkrits með innri lykkju

Óskgildið $U$ fer inn í samlagningarpunkt (+, −) með einingarafturvirkni frá úttakinu $Y$. Þaðan fer merkið í gegnum $G_1 = \dfrac{1}{s+1}$ og síðan $G_2 = \dfrac2s$, en utan um $G_2$ er innri neikvæð afturvirkni með $H = 0{,}5$. Finnið $Y/U$ og jafnvægisgildi þrepasvörunar.

1. Innri lykkjan fyrst:

$$\frac{G_2}{1 + G_2H} = \frac{2/s}{1 + 1/s} = \frac{2}{s+1}$$

2. Raðtenging við $G_1$: $\;G_{fram} = \dfrac{1}{s+1}\cdot\dfrac{2}{s+1} = \dfrac{2}{(s+1)^2}$

3. Ytri lykkjan:

$$\frac YU = \frac{G_{fram}}{1 + G_{fram}} = \frac{2}{(s+1)^2 + 2} = \frac{2}{s^2 + 2s + 3}$$

Jafnvægisgildi $G(0) = $ 2/3. Annarrar gerðar með $\omega_n = \sqrt3 = 1{,}73$ rad/s og $\zeta = 1/\sqrt3 = 0{,}577$ (sjá tímasvörun). Innri lykkjan breytti heildinu $2/s$ í fyrstu gerðar kerfi, svo lykkjan er tegund 0 og skekkjan $1/3$.
